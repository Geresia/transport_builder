# Transport Builder

Transit demand modeling and visualization tools for regional population data.

## Directories

- **transitline** — Regional population density and OD-flow maps for transit planning
- **bot** — Data ingestion and processing
- **depot** — Demand modeling and analysis
- **monorepo** — Analytics dashboard and frontend
- **registry** — Configuration and schema definitions
- **template-mod** — Map templates and generation scripts

## Key Features

- Population density mapping by administrative division (동-level)
- Origin-destination flow analysis by time and purpose
- Multi-region coverage (Seoul, Daegu, Busan, Gyeongsan, Gumi, Chilgok)
- Interactive web-based transit demand visualization

See `transitline/docs/region-map-playbook.md` for data production workflow.
