# 역 설계·입찰·시공 경영 UI 구현 보고서

- 기준일: 2026-09-26
- 금액 기준: 2026년 일본 엔, `JPY`
- 구현 단계: A5 완료
- 담당 경계: 지도는 후보지와 공간 사실을 제공하고, 경영 엔진은 기술·사업비·계약·공정을 판단한다.

## 1. 플레이 흐름

시나리오 화면에서 한 역이 다음 순서로 진행된다.

```text
지도에서 역 선택
  -> 출입구·환승통로·작업장 후보 선택
  -> 구조·배선·편성·자동운전 등 상세설계
  -> 위반 또는 조건부 항목 확인
  -> 조건부 항목의 추가비·추가기간 확정
  -> 시공사 입찰
  -> 기술·안전·가격 비교 후 낙찰
  -> 계획된 모든 역 패키지 편입
  -> 노선 본공사 계약
  -> 공사·중단·시험·사용 가능
  -> 개통 또는 사업 취소
```

샌드박스의 자유로운 노선 그리기는 유지하되, 시나리오에서는 모든 계획 역에 낙찰된 상세 패키지가 있어야 노선 본공사 계약 버튼이 열린다.

## 2. 화면에 노출한 설계 항목

- 구조 형식과 승강장 배선
- 현재 운행 편성량과 미래 구조 대응 편성량
- 운전 방식과 승강장 안전문
- 지도에서 선택한 출입구, 환승통로, 작업장
- 작업장 사용권 확보 여부
- 지도 입력 품질과 역 후보 식별값
- 설계 위반과 조건부 판단
- 조건 해소에 필요한 추가 공사비와 추가 개월
- 시공사별 입찰가, 기술점수, 안전점수와 종합순위
- 상세 낙찰비가 기존 개략 역 공사비를 대체한 금액
- 역 패키지 상태, 공정률과 노선 기성금 중 배분액

지도에서 선택한 값은 `transitline:station-selection` 이벤트를 통해 경영 패널로 전달된다. 지도 선택 모듈은 비용·기간·공법·보상·낙찰을 결정하지 않으며 경영 엔진의 현금과 공사 상태를 수정하지 않는다.

## 3. 계약과 개통 관문

노선 본계약 가능 조건은 다음과 같다.

1. 노선 계획이 견적 또는 승인 상태다.
2. 계획된 역마다 정확히 하나의 상세 패키지가 있다.
3. 각 패키지는 시공사 낙찰까지 끝났다.
4. 상세 역 패키지 전부를 노선 총사업비에 편입했다.

상세 역 비용은 기존 노선 견적에 더하지 않는다. 기존 역별 개략비를 제거하고 낙찰가로 교체하므로 이중계상되지 않는다. 역 패키지가 모두 사용 가능 상태가 아니면 영업 개통도 차단된다.

## 4. 취소 처리

시나리오 화면에 사업 취소 명령을 연결했다. 실행 전에 확인창을 표시하며 취소 뒤에는 다음 처리가 함께 일어난다.

- 노선 프로젝트를 `cancelled`로 전환
- 남은 공사 약정 해제
- 이미 지출된 비용은 매몰비용으로 유지
- 연결된 역 패키지를 `cancelled`로 전환
- 시공사 수주 여력 반환
- 지도에서 공사 중단과 다른 취소 표시 사용
