# 로그인 게이트 데이터 받는 법 (Playbook §2–3 입력)

`build-metro-demand.mjs` (§1) 이 쓰는 `pop.csv` · `hjd.geojson` 은 로그인 없이 받힌다.
하지만 §2(생활이동·승하차 원본) 과 §3(통근통학 OD) 는 **data.go.kr / KOSIS 의 파일
다운로드 버튼**이라 세션이 필요하고, 헤드리스(agent)로는 못 받는다. 사람이 한 번 받아
스크래치패드에 넣어주면 그다음은 자동.

받은 파일은 전부 **작업 스크래치패드 한 곳**에 둔다. 경로는 진행 중인 세션에 물어보면
알려줌 (예: `.../scratchpad/pb/`).

---

## 공통 — data.go.kr 파일 받기

1. <https://www.data.go.kr> 우상단 **로그인** → 없으면 회원가입(무료) 또는 네이버/카카오 간편로그인.
2. 데이터셋 페이지 열기 (아래 표의 URL).
3. **"다운로드"** 버튼 클릭 → 활용목적 간단히 선택하는 팝업이 뜨면 아무거나 선택 → 파일 저장.
   - 컬럼정의서(엑셀)도 같이 받아두면 인코딩·컬럼명 확인에 좋음.
4. 대부분 **EUC-KR(CP949) 인코딩 CSV**. UTF-8 변환은 빌드 스크립트가 알아서 하니 그대로 저장.

### 3번 — KOSIS 통근통학 OD 받는 절차

1. <https://kosis.kr> → 통계표 검색창에 **"거주지 및 통근·통학지별 통근·통학"** 또는 **"통근통학 인구"**.
2. 「인구총조사 > 표본집계 (인구·가구 기본항목) > **거주지 및 통근·통학지별 통근·통학 인구(12세 이상)**」
   계열 표를 연다 (최신 = 2020, 2025 총조사 결과 나오면 교체).
3. 조회 조건:
   - **거주지**: 대구광역시 전체 시군구 + 경산시·구미시·칠곡군
   - **통근·통학지**: 전체 (또는 최소한 위 12개 + "기타")
   - 항목: 통근·통학 인구(계). 성별·수단은 불필요.
4. 우상단 **다운로드 → CSV** (또는 XLSX). 피벗 안 된 "행렬" 형태로.
5. 안 되면 대안: **SGIS 자료제공** <https://sgis.kostat.go.kr/view/pss/openDataIntrcn> 의
   통근통학 데이터, 또는 통계주제도 `data.go.kr/15140470` (단 이쪽은 시각화용이라 원자료가 약함).

> KOSIS 표 다운로드는 보통 로그인 없이 되지만, 대용량은 "대용량 통계" 신청이 필요할 수 있음.
