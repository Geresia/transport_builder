# A7-1 공사계약 물가조정 정산 구현 보고서

- 기준일: 2026-09-28
- 통화·가격 기준: 2026년 일본 엔(JPY)
- 범위: 공구별 시공계약의 물가 지수 정산, 총사업비·현금 약정 반영, 저장·복원

## 구현 목적

A7에서 계약 방식별 물가위험 부담률을 계약 데이터로 보존했지만 실제 공사비에는 반영하지 않았다. 이번 단계에서는 총액고정, 물가연동, 목표원가 계약의 차이가 공사 중 발주자 부담액과 시공사 흡수액으로 나타나게 했다.

## 계산 규칙

각 공구의 정산액은 다음 식으로 계산한다.

```text
미완성 기준금액 = 최초 계약 P50 × (1 - 공구 진행률)
총 물가상승액 = 미완성 기준금액 × (현재 지수 - 직전 정산 지수) / 기준 지수
발주자 부담액 = 총 물가상승액 × 계약별 발주자 부담률
시공사 흡수액 = 총 물가상승액 - 발주자 부담액
```

발주자 부담률은 기존 A7 계약 조건을 그대로 사용한다.

| 계약 방식 | 발주자 물가 부담률 |
| --- | ---: |
| 총액고정 `fixed-price` | 10% |
| 물가연동 `index-linked` | 75% |
| 목표원가 `target-cost` | 50% |

공구 진행률은 연결된 통합 공정표 작업들의 기간가중 평균으로 계산한다. 이미 완료된 물량에는 나중의 지수 상승을 소급하지 않는다. 동일 지수의 중복 정산은 0원이며 정산 이력도 추가하지 않는다. 현재 범위는 기준 지수 100 이상의 상승 정산만 지원하며 직전 정산 지수보다 낮은 값은 거절한다.

## 상태와 회계 반영

계약에는 `priceIndexBase`, `lastSettledPriceIndex`, `priceAdjustments[]`를 저장한다. 각 이력에는 지수 구간, 공구 진행률, 미완성 기준금액, 총 상승액, 발주자 부담액, 시공사 흡수액, 연결 사건 ID와 정산 시각이 들어간다.

발주자 부담액은 다음 상태에 동시에 반영된다.

- 공구 계약 `currentPriceP50`과 `priceP90`
- 프로젝트 `estimate.totalP50`과 `estimate.totalP90`
- A7 계약 대체 집계의 낙찰액과 기존 공사비 대비 증감액
- 프로젝트의 남은 건설 현금 약정

정산 자체는 즉시 현금을 지급하지 않는다. 늘어난 약정액은 이후 월별 기성 지급을 통해 현금에서 빠져나간다. 약정을 늘릴 가용현금이 부족하면 거래 전체를 원상복구한다.

## API

- 계산 함수: `settleConstructionPriceIndex(schedule, project, priceIndex, clock, options)`
- 경영 명령: `ManagementGame.settleConstructionPriceIndex(scheduleId, priceIndex, options)`
- 시나리오 명령: `ScenarioRuntime.settleConstructionPriceIndex(planId, priceIndex, options)`
- 사건 연결: `options.sourceEventId`

## 검증 범위

- 세 계약 방식의 서로 다른 발주자 부담률
- 공구 진행분을 제외한 잔여 물량 정산
- 같은 지수 중복 입력의 멱등성
- 여러 차례 지수 상승의 증분 정산
- 총사업비와 남은 건설 약정의 동시 갱신
- 저장·불러오기 후 정산 이력과 계약 금액 유지
- 직전 정산 지수보다 낮은 값 거절
