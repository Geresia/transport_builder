- 구현 단계: A4 완료

## 1. 구현 결과

Claude가 만든 `StationSiteGeometry v1`을 경영 엔진의 다음 세 객체로 변환하는 계약 어댑터를 구현했다.

```text
StationSiteGeometry
  -> StationPlan
  -> StationAccessPlan
  -> StationConstructionContext
  -> 역 상세견적
  -> 조건 해소
  -> 시공사 입찰·낙찰
  -> 노선 본공사 편입
  -> 공사·시험·사용 가능·취소
```

지도값은 원본 그대로 보존한다. `roadWidthMeters: null`은 0 m가 아니며, `publicLand: null`은 사유지가 아니다. 건물 충돌 수가 미상이면 0건으로 확정하지 않고 상세견적 단계에서 별도의 보수적 추정값과 근거를 남긴다.

## 2. 지도 계약 변환 규칙

`station-site-adapter.mjs`가 지도 후보와 경영 결정을 분리한다.

- `planHints`는 기본 선택을 돕는 참고값일 뿐 지도 판단으로 취급하지 않는다.
- 출입구 후보 중 실제 선택된 후보만 역 계획에 들어간다.
- 출입구 폭, 접근거리, 장애인 동선은 경영 엔진의 설계값 또는 명시적 가정이다.
- `publicLand: null`은 그대로 유지하며 무상 부지로 계산하지 않는다.
- 환승 후보는 플레이어가 선택해야만 실제 환승통로가 된다.
- 다른 계획의 역으로 연결되는 환승은 외부 목적지 ID로 유지한다.
- 작업장 후보가 있다는 사실과 작업장 사용권을 확보했다는 사실을 구분한다.
- 작업장을 명시적으로 확보했고 건물·수역·도로 충돌이 모두 0으로 확인된 경우에만 공사용 수직구 확보로 인정한다.
- 본체 크기가 기본값 또는 계획 승강장 길이에서 온 자리표시 값이면 상세설계 조건을 남긴다.
- 미래 편성에 필요한 승강장 길이가 양 끝 연장 가능 공간보다 길면 시공 불가 사유가 된다.

## 3. 시공사 시장과 입찰

역 공사 시공사는 다음 속성을 가진 지속 객체다.

- 적용 가능한 공법
- 기술점수
- 안전점수
- 가격 성향
- 동시 수행 가능 패키지 수
- 현재 수주잔고
- 완료 실적

입찰 전에는 기술 위반이 없어야 하며, 조건부 판단은 조치 내용·추가비·추가기간으로 해소해야 한다. 입찰가는 상세 P50, 조건 해소비, 시공사 가격 성향, 수주잔고와 난수를 사용해 계산한다. 평가는 가격 50%, 기술 30%, 안전 20%이며 동일 점수일 때 더 낮은 가격을 우선한다.

낙찰되면 시공사 수주잔고가 증가한다. 준공 또는 취소 시 수행 여력이 반환되고, 준공한 경우 완료 실적이 증가한다.

## 4. 공사비 이중계상 방지

기존 노선 개략견적에는 역별 개략 공사비가 이미 포함돼 있다. 상세 역 패키지를 붙일 때 다음 방식으로 교체한다.

```text
조정 노선 P50
= 기존 노선 P50
- 해당 역의 개략 공사비·시스템·관리·시험·예비비 배분액
+ 해당 역 시공사의 낙찰 P50
```

P90도 같은 방식으로 개략 배분액을 제거하고 낙찰 P90으로 교체한다. 상세 역 계약을 별도 원장 약정으로 다시 잡지 않는다. 노선 본계약의 약정 하나가 조정된 전체 P50만 보유하고, 역 패키지의 `paidAllocation`은 그 기성금 중 해당 역에 배분된 보고값이다.

일부 역만 상세설계한 경우 사업비 비교는 가능하지만 본공사 계약은 할 수 없다. 계획된 모든 역에 정확히 하나의 낙찰 패키지가 있어야 노선 본계약이 가능하다.

## 5. 생애주기와 개통 관문

역 패키지 상태는 노선 프로젝트와 동기화된다.

| 노선 상태 | 역 패키지 상태 |
|---|---|
| 낙찰 후 계약 전 | `awarded` |
| 계약·본공사 | `underConstruction` |
| 공사 일시중단 | `suspended` |
| 종합시험 | `testing` |
| 사용 가능 | `available` |
| 사업 취소 | `cancelled` |

노선이 물리적으로 완성돼도 상세 역 패키지가 모두 `available`이 아니면 영업 개통 준비검사에서 탈락한다. 취소 시 남은 노선 공사 약정은 해제되고 이미 지급한 금액만 매몰비용으로 남으며 역 패키지와 지도 표시도 취소 상태를 받는다.

## 6. 게임 API와 저장

`ManagementGame`에 다음 명령을 추가했다.

- `designStationPackage()`
- `resolveStationPackage()`
- `tenderStationPackage()`

- `integrateStationPackages()`

시공사 목록, 입찰서, 낙찰가, 조건 해소 기록, 조정된 노선 사업비, 역 공정 상태는 저장·불러오기 대상이다. 이전 저장에 시공사 목록이 없으면 국가 프로필에 맞는 기본 시장을 생성한다.
