## 0. 보고서 결론

이 게임의 철도는 선을 긋는 순간 생기는 시설이 아니다. 플레이어가 자유롭게 노선을 제안할 수는 있지만 다음 여섯 시스템이 모두 맞아야 건설되고 개통된다.

여섯 시스템에 들어가기 전에는 자체사업·민간제안·공공공모·기존사업 인수 중 하나로 사업권과 재원을 확보한다. 이 상위 과정은 [사업 수주·사업성·경쟁회사 설계보고서](transport-business-award-economics-competition-kr-jp-2026.md)에서 다루며, 수주가 확정되면 아래 여섯 시스템을 가진 `RailProject`가 생성된다.

```text
① 차량이 달릴 수 있는 철도 규격과 실제 선로
→ ② 차량과 승객을 받을 수 있는 역·승강장·회차시설
→ ③ 지형과 도시에 맞는 공법·공정·공사 계약
→ ④ 노선 수요와 배차에 맞는 차량·편성·보유량
→ ⑤ 차량을 제때 공급할 제작사·발주·검사 계약
→ ⑥ 차량을 세우고 검사·정비할 차량기지
→ 통합시험·운영 준비·승인
→ 개통
```

실제 사업에서는 이 작업이 완전히 직렬로 진행되지 않는다. 토목공사를 하는 동안 차량을 발주하고 기지를 건설하며 인력을 훈련한다. 게임도 병행을 허용하되 선행 조건을 어기지는 못하게 한다.

플레이어가 받는 재미의 핵심은 정답 선형을 찾는 것이 아니라 다음 선택을 경영하는 것이다.

- 작은 차량과 급곡선으로 공사비를 줄일 것인가, 큰 차량으로 장기 수요를 받을 것인가.
- 지상·고가로 싸게 지을 것인가, 보상·민원을 피해 지하로 갈 것인가.
- 역을 많이 지어 접근성을 높일 것인가, 역 수를 줄여 속도와 사업비를 잡을 것인가.
- 싼 제작사를 골라 납기·품질 위험을 감수할 것인가.
- 기지를 외곽에 싸게 짓고 평생 회송비를 낼 것인가, 도심 지하에 비싸게 지을 것인가.
- 국가·지자체의 지원을 받는 대신 노선·역·요금·서비스 조건을 받아들일 것인가.

샌드박스는 자금·승인·주민갈등을 끌 수 있지만, 물리 호환성·건설시간·차량과 기지 필요 여부는 각각 별도 옵션으로 둔다. 무제한 자금이 곧 즉시 건설을 뜻하지 않는다.

## 1. 한국과 일본을 게임에서 어떻게 구분할 것인가

### 1.1 공통점

양국 모두 실제 철도사업은 수요와 사업성 검토, 노선·역 계획, 설계, 용지와 환경 협의, 발주, 토목·궤도·전기·건축 공사, 차량 제작, 시험과 개통의 순서를 거친다. 국가가 돈을 준다고 공사가 자동으로 끝나지 않으며, 민간사업자가 제안했다고 노선과 역을 마음대로 확정할 수도 없다.

### 1.2 제도와 사업구조의 차이

| 항목 | 한국에서 익숙한 형태 | 일본에서 게임에 반영할 형태 |
|---|---|---|
| 초기 계획 | 시·도 도시철도망이나 국가철도망에 반영하고 예타·기본계획을 거치는 공공 주도 비중이 큼 | 국가·도시권 계획, 지자체 도시계획, 철도사업자 제안과 기존 사철망 전략이 함께 작용 |
| 노선·역 확정 | 노선별 기본계획에 개략 노선·정거장·사업비·재원을 담고 주민의견과 승인을 거침 | 지자체와 사업자가 수요·도시개발·사업허가·비용분담을 조정하며, 역 요청이 자동 채택되지 않음 |
| 사업성 | B/C와 정책성·지역균형을 포함한 예타·타당성 검토가 강한 관문 | 수요·채산성·공공성·운영주체와 보조제도를 사업별로 조합. 제3섹터와 상하분리도 사용 |
| 재원 | 국가·지자체 분담, 공기업 또는 민자 BTO·BTL 등 | 사업자 자체투자, 국가·지자체 보조, 공공 인프라 보유와 운영 분리, 제3섹터 등 조합이 다양 |
| 차량 안전 | 형식승인·제작자승인·완성검사 체계가 명시적 | 성능기준 아래 사업자가 실시기준을 만들고 차량 확인·검사와 사업자 책임을 결합 |
| 지역갈등 | 보상·수용·민원과 지자체 간 부담 갈등이 착공·개통을 지연 | 같은 갈등이 존재하지만 장기간 사전협의 때문에 착공 전 단계에서 사업이 멈추기도 함 |
| 역·기지 부대개발 | 이전부지 개발, 복개, 공원·체육시설과 결합 | 철도회사가 역·기지 상부와 유휴부지를 장기 임대·상업개발해 비운임수입으로 연결하는 사례가 많음 |

한국 도시철도는 도시철도망 구축계획, 예비타당성조사, 노선별 기본계획, 기본·실시설계, 사업계획 승인, 시공·준공으로 이어진다. 기본계획에는 수요, 노선·정거장, 사업기간·총사업비·재원과 건설방식이 들어간다. [대도시권광역교통위원회 도시철도 절차](https://www.molit.go.kr/mtc/USR/WPGE0201/m_37143/DTL.jsp)

일본 JRTT는 조사·계획, 관계기관 협의, 환경평가, 설계, 용지취득, 발주·시공관리, 토목·궤도·건축·기계·전기 공사, 검사와 개업을 한 흐름으로 설명한다. [JRTT 철도가 만들어지는 과정](https://www.jrtt.go.jp/construction/process/)

### 1.3 게임에서의 국가 처리 원칙

`한국 가격 × 일본 국가배율` 같은 단일 변환은 쓰지 않는다. 실제 사업비는 구조·역 밀도·차량 크기·도심 지장물·지반·보상·기존선 접속·가격 기준연도의 영향을 훨씬 크게 받는다.

국가 프로필은 다음을 바꾼다.

- 계획·승인 단계와 담당 기관.
- 국비·지방비·사업자 부담 계약의 기본 템플릿.
- 차량·시설의 검사 절차.
- 발주 방식과 계약 조건 후보.
- 토지·지하사용권과 주민협의 사건.
- 노무·물가·공급자 시장의 지역 보정값.

철도 물리법칙과 호환성 검사는 국가가 달라도 같은 방식으로 실행한다.

## 2. 전체 플레이 흐름

### 2.1 사업을 시작할 때

```text
교통문제·개발계획·공모사업 확인
→ 플레이어가 노선·서비스 개념 제안
→ 수요·경쟁노선·정책목표 검토
→ 대안 노선과 철도 시스템 비교
→ 개략 비용·공기·사업성 제시
→ 자비사업 / 보조사업 / 공공발주 운영권 경쟁 결정
```

국가나 지자체가 노선과 역을 정해 운영사업자를 모집하는 시나리오도 있고, 플레이어가 민간 제안으로 노선과 역을 제안하는 시나리오도 있다. 어느 한 방식만 게임 전체 규칙으로 고정하지 않는다.

### 2.2 설계·건설·개통

```text
철도 규격 확정
→ 구간별 구조와 선로 배치
→ 역·승강장·환승·회차 계획
→ 지반·지장물·용지 조사
→ 기본설계와 사업비·공기 갱신
→ 사업 승인과 재원·협약 확정
→ 시공사·설비사·차량 제작사 계약
→ 토목·역·기지 공사와 차량 제작 병행
→ 궤도·전력·신호·통신·역 설비 설치
→ 차량 반입·기지 시험·노선 종합시험
→ 최소 서비스·안전·인력·계약 검사
→ 개통
```

### 2.3 다섯 개의 관문

| 관문 | 통과 조건 | 실패하면 |
|---|---|---|
| G1 사업성 | 수요·재원·운영주체·정책조건이 최소 기준 충족 | 계획 보류, 노선·역·시스템 수정 |
| G2 기술성 | 규격·선형·구조·역·기지 후보가 물리적으로 가능 | 재설계 또는 조사 추가 |
| G3 착공 | 승인·핵심용지·설계·계약·착공자금 확보 | 공사 시작 불가 |
| G4 통합시험 | 선로·역·전력·신호·차량·기지·인력이 연결 | 결함 수정, 개통 지연 |
| G5 영업개시 | 안전·서비스·운임·운영·비상대응 조건 충족 | 시설이 완공돼도 수입 발생 불가 |

## 3. 시스템 1 — 철도 규격·구조·선로

### 3.1 플레이어가 고르는 것

1. 기존 노선 직통, 환승 연결, 독립망 중 하나를 선택한다.
2. 주행 시스템과 차량 크기 범위를 선택한다.
3. 궤간·급전·전압·공간·축중·신호 규격을 정한다.
4. 구간별 지상·성토·절토·고가·교량·지하 구조를 정한다.
5. 단선·복선·복복선, 대피선, 분기, 건넘선과 회차 경로를 배치한다.
6. 곡선·경사·분기 속도와 차량 성능을 대조한다.

### 3.2 주행 시스템 초기 카탈로그

아래 가격은 2026년 일본 엔 기준 게임 초기값이며 실제 제작사의 견적이 아니다.

| 고무차륜 AGT | 10.0×2.50m | 1.40억 엔 | 소형·고빈도·무인운전과 결합 용이 | 긴 거리·대량 수송 효율과 타이어 유지비 |

LRT·노면전차는 도로와의 상호작용이 필요하므로 전용궤도형부터 후속 지원한다. 도로를 유지한다는 게임 범위상 자동차 도로 자체를 플레이어가 재설계하지는 않는다.

### 3.3 반드시 분리할 개념

```text
주행 시스템 ≠ 구조 형식 ≠ 선로 수 ≠ 서비스 종류 ≠ 정차 패턴
```

모노레일은 주행 시스템이고 고가는 구조다. 급행은 정차 패턴이고 복복선은 선로 구성이다. 지하철이라고 같은 궤간·급전·차량한계를 쓰는 것도 아니다.

도쿄도 교통국만 보더라도 노선에 따라 1,067mm·1,372mm·1,435mm 궤간이 존재한다. 일본 전체를 단일 규격으로 처리하지 않는다. [도영지하철 노선 규격](https://www.kotsu.metro.tokyo.jp/about/service/subway.html)

### 3.4 호환성 판정

다음 항목을 모두 확인한다.

```text
주행·안내 방식
궤간
집전 방식과 전압·주파수
차량한계와 곡선 편위
축중과 구조물 하중
최소곡선·최대경사·제동 성능
차상·지상 신호와 자동운전 인터페이스
승강장 높이·문 위치·홈도어
기지 입출고 경로와 정비설비
시설 사용계약
```

판정은 `가능 / 조건부 / 불가능 / 자료 부족`으로 나눈다. 자료 부족은 가능으로 통과시키지 않는다. 궤간만 같다고 직통할 수 없고, 자력 운행이 불가능해도 별도 견인차와 안전조건이 있으면 공장 회송만 가능할 수 있다.

### 3.5 선로와 운행 효과

| 대피선 | 일부 급행 운행 가능 | 역 확장과 분기기·시간표 정밀화 필요 |

## 4. 시스템 2 — 역·승강장·환승·회차

### 4.1 역은 한 점이 아니다

역은 다음 자산의 묶음이다.

```text
역 구조물
+ 승강장과 각 승강장 가장자리
+ 역 구내 선로·분기·회차시설
+ 출입구·개찰구·대합실
+ 계단·에스컬레이터·엘리베이터
+ 환승통로
+ 환기·배수·전력·통신·방재
+ 홈도어·안내·감시설비
```

출입구 위치는 지도 계층에서 접근 수요와 보행시간을 받는다. 시스템은 그 동선의 처리량과 건설·운영 상태를 계산한다.

### 4.2 승강장 길이

```text
편성길이 = 각 차량 실제 길이의 합 + 모델상 연결부
영업 유효길이 = 편성길이 + 정차오차 여유 + 양단 안전여유
건축길이 = 영업 유효길이 + 양단 설비·구조 구간
```

게임 초기 간편설계에서는 자동운전·정위치정차 노선은 편성 양단 합계 5m, 일반 유인운전은 합계 10m의 계획 여유를 제안값으로 보여준다. 이는 법정 공통치가 아니라 상세 차량·신호 프로필이 없을 때 쓰는 게임 가정이다. 실제 확정은 차량 문 위치, 곡선, 홈도어와 정차성능으로 다시 검사한다.

장래 8량화를 고려해 구조물은 8량 길이로 만들고 현재 6량 구간만 마감하는 선택을 허용한다. 미마감 구간은 영업 승강장으로 계산하지 않는다.

### 4.3 승강장·선로 템플릿

| 템플릿 | 적합한 용도 | 경영상 효과 |
|---|---|---|
| 복선 상대식 | 일반 중간역 | 단순하지만 양쪽 수직동선 비용 발생 |
| 복선 섬식 | 방향 전환·공용동선 | 시설을 공유하나 중앙 폭과 혼잡 관리 필요 |
| 2면 3선 | 종착·대피·시종착 열차 | 운행 유연성 증가, 진로 상충 가능 |
| 2면 4선 | 급행 통과·대피 | 급행효과 확보, 역 구조비와 부지 증가 |
| 쌍섬식 4선 | 동일 승강장 환승 | 환승 편의가 높지만 구조와 계단 병목이 큼 |
| 층별 분리 | 좁은 도심·입체분기 | 평면 폭 절감, 깊이·수직환승 비용 증가 |
| 두단식 종착 | 터미널 | 승객 동선은 좋지만 도착·출발 충돌 관리 필요 |

모노레일·AGT에는 일반 철도 템플릿의 숫자만 바꾸지 않는다. 궤도빔·안내궤도·비상통로·문 위치가 포함된 전용 템플릿을 사용한다.

### 4.4 역 구조와 초기비용

2026년 일본 게임 초기값, 120m 승강장 기준이다. 용지·보상·대형 환승통로·특수지반·차량·기지는 제외한다.

| 역 종류 | 기본 패키지 | 주요 추가비 |
|---|---:|---|
| 지상역 | 20억 엔 | 보행교·도로 입체교차·방음·부지 |
| 고가역 | 45억 엔 | 대형 기초·교각 충돌·긴 수직동선 |
| 표준 지하역 | 120억 엔 | 지장물·교통처리·환기·출입구 보상 |
| 20~30m 깊이 | 표준 지하역 ×1.25 | 수직동선·피난·환기 증가 |
| 30~40m 깊이 | 표준 지하역 ×1.55 | 대형 굴착·깊은 출입구와 환승 |
| 40~50m 깊이 | 표준 지하역 ×1.90 | 대심도형 수직운송·피난 부담 |

승강장 길이 패키지 계수는 `H = 0.5 + 0.5 × 승강장길이/120m`를 60~240m 범위에서 임시 사용한다. 상세 물량 계산으로 전환하면 이 계수를 다시 곱하지 않는다.

### 4.6 역 용량과 회사 손익

```text
유효승강장면적 = 총면적 - 기둥·벽·설비 - 안전영역 - 동선보호영역

정차시간 = 문 개폐·확인 고정시간
         + max(문별 승차시간, 문별 하차시간, 혼재간섭시간)
         + 혼잡·안전설비·운영 추가시간
```

역을 작게 지으면 초기비는 줄지만 정차시간 증가, 승객 잔류, 안전 제한과 증편효과 상실이 발생한다. 역을 크게 지으면 건설·냉난방·청소·보수비가 늘어난다. 환승통로가 짧아지면 이용객은 늘 수 있지만 토목비와 다른 사업자에게 지불할 연결비가 증가한다.

### 5.3 견적 계산

```text
직접공사비 C = 토목구조 + 궤도·주행로 + 전력·신호·통신
             + 역·기지 + 분기·회차 + 환경저감 + 별도공사

조사·설계·사업관리 D = 시설 직접비 × 8%        # 초기 게임값
통합시험·도입준비 R = 전체 직접비 × 1% + 최초 기술준비비
기준견적 B = C + D + R
예산준비액 = B + 위험예비비 + 용지·보상 + 금융비 + 세금
```

초기 미조사 단계는 `B의 75~150%`, 기본설계 뒤에는 `B의 90~120%`를 예상 범위로 표시한다. 이 범위는 통계적 신뢰구간이 아니며 누락된 용지·특수공사를 0엔으로 만들지 않는다.

### 5.4 공정망

```text
조사·측량·지반조사
→ 기본설계·환경·관계기관 협의
→ 상세설계·용지·지장물 협의
→ 공구 분할과 시공사 선정
→ 가설·이설·작업구
→ 토목구조
→ 궤도·주행로
→ 전력·신호·통신
→ 역·기지 설비
→ 개별검사
→ 차량을 사용한 통합시험
→ 개통
```

독립 공구는 병행할 수 있다. 같은 작업팀·TBM·대형 장비·야간 선로차단 시간을 여러 프로젝트가 동시에 쓸 수는 없다.

### 5.7 한국과 일본의 공사 흐름 차이

- 한국 시나리오는 망계획·예타·기본계획·사업계획 승인과 국가·지자체 재원분담이 중요한 초기 관문이다.
- 일본 시나리오는 사업자·지자체·시설보유주체의 역할과 보조·상하분리 계약이 사업마다 달라진다.
- 양국 모두 실제 현장은 토목·궤도·건축·기계·전기 공종과 용지·주민 대응이 분리되며 종합 공정관리가 필요하다.
- 한국의 공개 사업비와 일본의 공개 사업비는 포함 범위와 기준연도가 다르면 직접 단가로 비교하지 않는다.

### 5.8 지연 사건

지질, 설계변경, 용지·권리, 지장물, 물가·노무, 조달, 사고, 재해, 차량·신호 통합을 독립 원인으로 기록한다. 단일 `랜덤 지연`으로 처리하지 않는다.

다음은 일본의 길이 10~20km, 역 8~15개, 지하·고가 혼합, 착공 후 8년, 일정예비 9개월인 표준 도시철도에 적용할 게임 초기값이다. 공식 전국 평균이 아니다. 일본 국토교통성 자료에는 사업평가·계약변경·건설사고가 따로 공개되지만, 원인별 도시철도 개통 지연률을 바로 계산할 공통 분모가 없기 때문이다. 한국 프로필도 동일한 원인 구조를 쓰고 국내 사례로 도시·사업유형 계수를 따로 보정한다.

| 위험요인 | 사업 중 1회 이상 발생 | 공식 개통지연까지 진행 | 발생 시 기본 영향 |
|---|---:|---:|---|
| 지질·지하수·기초공법 변경 | 35% | 18% | 3~24개월 |
| 설계변경·기존 구조물 접속 | 35% | 15% | 2~18개월 |
| 용지·지하권·관계자 협의 | 30% | 18% | 6~36개월 |
| 지장물·매장문화재 | 25% | 12% | 1~12개월 |
| 자재·노무비 급등과 예산변경 | 45% | 15% | 비용 +5~25%, 0~12개월 |
| 자재·장비·차량부품 조달지연 | 25% | 12% | 2~12개월 |
| 입찰 불성립·시공사 인력부족 | 25% | 14% | 3~18개월 |
| 1개월 이상 핵심공정 중단 사고 | 8% | 6% | 1~12개월 |
| 1년 이상 지연시키는 중대사고 | 2% | 2% | 12~36개월 |
| 지진·홍수·태풍 등 재해 중단 | 6% | 4% | 1~12개월 |
| 차량·신호·통합시험 문제 | 10% | 5% | 1~9개월 |

원인은 동시에 일어날 수 있으므로 위 확률을 더하지 않는다. 표준선의 최종 개통분포는 `목표 범위 55% / 1~6개월 지연 15% / 7~18개월 15% / 19~36개월 10% / 37개월 이상 5%`로 시작한다. 즉 한 달 이상 개통 지연 45%, 7개월 이상 30%, 19개월 이상 15%다. 사건의 근거·도시별 계수·40km 지하 AGT 보정은 [일본 철도사업·지연 모델](japan-rail-project-system-agt-case.md#11-지연-확률-초기값)에 둔다.

## 6. 시스템 4 — 차량·편성·보유자산·운행 성능

### 6.1 세 계층

```text
VehicleModel     제작사 카탈로그와 기술 사양
TrainFormation   몇 량을 어떤 순서와 동력구성으로 묶는가
RollingStockUnit 실제로 소유·리스한 개별 편성
```

같은 모델이라도 각 편성은 납품일, 누적거리, 검사기한, 고장·수리, 배속 노선과 기지를 따로 가진다. 차량은 운행이 끝나면 사라지는 효과가 아니라 회사 자산이다.

### 6.2 모델에 저장할 것

- 주행 방식, 궤간, 급전·전압, 신호·ATO 호환.
- 길이·폭·높이, 중량·축중, 곡선 편위.
- 허용 편성 조합과 동력차·부수차 구성.
- 정원·좌석·문 수·문 위치·문 폭.
- 최고속도, 가속·제동, 경사·곡선 성능.
- 에너지 사용, 소음, 차륜·타이어·안내장치 마모.
- 일상검사·정기검사·중정비 요구.
- 구매가, 예비품, 보증, 부품공급 기간.

### 6.3 필요한 편성 수

```text
왕복주기분 = 상행 주행 + 종점정차·회차 + 하행 주행 + 반대 종점 회차

기본 운행편성 = ceil(왕복주기분 / 목표배차간격분)

필요 보유편성 = 기본 운행편성
              + 첨두 증편
              + 정기검사 점유
              + 고장·사고 예비
              + 계약상 최소 예비
```

초기 예비율은 일반 철제차륜 10~15%, 특수 시스템·독립 소규모 차량군 15~20%를 제안값으로 표시한다. 실제 보유 수가 적을수록 한 편성 고장의 영향이 크므로 단순 비율 외에 최소 1~2편성 조건을 둔다.

예시:

```text
왕복주기 96분 / 목표배차 4분 = 운행 24편성
첨두 추가 1 + 검사 점유 2 + 고장예비 2 = 총 29편성
```

### 6.4 차량 선택의 장단점

| 선택 | 장점 | 단점 |
|---|---|---|
| 짧은 소형편성·고빈도 | 대기시간 감소, 작은 역 | 편성·운전횟수·정비건수 증가 |
| 긴 대형편성·저빈도 | 한 열차 수송력과 승무효율 | 큰 역·기지, 긴 대기시간과 과잉공급 가능 |
| 고가속 차량 | 짧은 역간거리에서 시간 단축 | 전력피크·차륜/타이어·설비 부담 |
| 다중전원·다중신호 | 직통 가능한 노선 증가 | 차량가격·중량·고장점·승인시험 증가 |
| 표준 카탈로그 | 가격·납기·신뢰성 유리 | 노선에 완전히 최적화되지 않을 수 있음 |
| 신규 맞춤모델 | 성능과 이미지 최적화 | 설계·시험·납기·초도고장 위험 증가 |

### 6.5 차량 상태

```text
발주 → 제작대기 → 설계·생산준비 → 제작중 → 공장검사
→ 운송 → 완성·인수검사 → 노선시험 → 영업가능

영업가능 → 유치 / 회송 / 영업 / 일상검사 / 정기검사
           / 고장수리 / 개조 / 장기보관 / 매각·폐차
```

납품됐다는 이유만으로 영업 투입하지 않는다. 시설·홈도어·신호·기지와의 통합시험을 통과해야 한다.

### 6.6 한국과 일본의 차량 확인

한국은 철도차량 형식승인, 제작자의 품질관리체계와 제작자승인, 판매 전 완성검사를 구분한다. 완성검사에는 형식동등성, 완성차 시험과 주행시험이 연결된다. [국토교통부 철도차량 승인 설명](https://www.molit.go.kr/USR/policyTarget/dtl.jsp?idx=691), [철도안전법 완성검사](https://www.law.go.kr/LSW/lsPdfPrint.do?ancYnChk=0&bylChaChk=N&efGubun=Y&efYd=20240419&joAllCheck=Y&joEfOutPutYn=on&lsiSeq=250117&mokChaChk=N)

일본은 국토교통성의 성능기준 아래 철도사업자가 자기 노선의 실시기준을 만들고 시설·차량 설계와 운전을 책임진다. 새로 설계한 차량이나 구조·장치가 달라진 차량에는 차량 확인 절차가 연결된다. [일본 철도 기술기준](https://www.mlit.go.jp/tetudo/tetudo_fr7_000036.html), [차량 확인 취급](https://www.mlit.go.jp/notice/noticedata/sgml/107/82000012/82000012.html)

게임에서는 절차 이름만 국가별로 달리하되 공통적으로 `설계 적합 → 생산 품질 → 완성차 → 노선 통합` 네 단계를 통과하게 한다.

## 7. 시스템 5 — 차량 제작사·발주·납품·보증

### 7.1 제작사는 차량 생성 버튼이 아니다

제작사는 다음 능력과 제약을 가진 회사 객체다.

```text
지원 주행 시스템과 차체 재질
설계·시험 기술
공장과 생산라인
현재 수주잔량과 사용 가능한 착수일
월별 생산량
품질·납기·재무 신뢰도
부품 공급망
보증·현장지원·장기 부품지원
```

실제 회사명과 성과를 임의 점수화하지 않는다. 기본 캠페인은 가상 제작사를 사용하고, 현실 회사는 검증된 공개자료를 갖춘 시나리오에서만 등장시킨다.

### 7.2 발주 흐름

```text
운행계획·필요 편성 계산
→ 요구사양서 작성
→ 제작사 사전심사와 입찰
→ 가격·성능·납기·유지비·위험 평가
→ 우선협상·사양확정
→ 계약·선급금
→ 설계동결·승인시험 준비
→ 초도차 제작·시험
→ 양산·편성별 완성검사
→ 배치별 운송·인수
→ 노선·기지 통합시험
→ 영업 투입·보증
```

한국에서 다원시스·현대로템과 같은 회사가 담당하는 것은 차량 설계·제작·납품이며, 토목 시공사와 차량기지는 별도다. 일본의 J-TREC 등도 설계·제조·검사·출하의 제조 흐름을 가진다. [J-TREC 업무 소개](https://www.j-trec.co.jp/src_saiyou/job/)

### 7.3 입찰 평가

| 평가군 | 기본 가중치 | 의미 |
|---|---:|---|
| 생애주기 비용 | 30 | 구매가, 전력, 정비, 부품, 개조 |
| 기술 적합성 | 25 | 규격·성능·안전·기지 호환 |
| 납기·생산능력 | 20 | 개통 전 필요한 편성 확보 가능성 |
| 품질·신뢰성 | 15 | 초도고장, 재작업, 가동률 위험 |
| 지원·보증 | 10 | 현장지원, 교육, 예비품, 장기부품 |

시나리오에 따라 공공조달은 가격 비중을 높이고, 혁신 차량은 기술·신뢰성 비중을 높인다. 입찰 최저가와 평가 최고점, 최종 계약자를 구분한다.

### 7.4 차량 조달 초기 생산값

| 시스템 | 생산대기 | 설계·준비 | 생산량/월/라인 | 운송·인수 |
|---|---:|---:|---:|---:|
| 일반 철제차륜 | 6개월 | 12개월 | 4량 | 3개월 |
| 리니어 | 9개월 | 18개월 | 2량 | 3개월 |
| 과좌식 모노레일 | 9개월 | 18개월 | 2량 | 3개월 |
| 현수식 모노레일 | 12개월 | 24개월 | 1.5량 | 3개월 |
| AGT | 9개월 | 18개월 | 3량 | 3개월 |

```text
전량 인수기간 = 생산대기 + 설계·준비
              + 발주량 ÷ 배정 생산량
              + 운송·인수
```

이는 실제 2026년 특정 회사의 생산능력이 아니라 공급자 시뮬레이션 초기값이다. 실제 게임에서는 제작사별 수주잔량과 라인 배정으로 대체한다.

### 7.5 계약과 지급

게임 기본 계약은 다음 지급 사건을 사용한다. 비율은 입찰 때 달라질 수 있는 게임값이다.

| 지급 사건 | 기본 비율 | 회사가 확인할 것 |
|---|---:|---|
| 계약·착수 | 15% | 생산 슬롯 확보, 보증서 |
| 설계동결·초도 준비 | 15% | 사양 변경 마감, 승인계획 |
| 제작 진척 | 40% | 배치별 기성, 부품 확보 |
| 납품·인수 | 25% | 편성별 검사와 소유권 이전 |
| 보증 유보·최종정산 | 5% | 하자·성능보증 종료 조건 |

실제 계약의 보편적 비율이라고 표시하지 않는다. 선급이 큰 계약은 제작사 착수가 빠르지만 플레이어의 선지급·부도노출이 커진다. 납품비중이 큰 계약은 플레이어를 보호하지만 제작사가 가격이나 금융비용을 높일 수 있다.

### 7.6 설계 변경과 지연

| 원인 | 결과 |
|---|---|
| 문 위치·편성 변경 | 차체·배선·홈도어·승강장 재검토 |
| 신호·ATO 변경 | 차상장치와 노선 통합시험 추가 |
| 다중전원·직통 추가 | 설계·중량·가격·승인기간 증가 |
| 원자재·반도체 지연 | 생산순서 변경·부분납품 |
| 초도차 시험 불합격 | 재설계·양산중단·개통 위험 |
| 제작사 생산슬롯 중복 | 착수 지연 또는 다른 업체·추가라인 비용 |
| 발주량 축소 | 편성당 가격 상승 가능 |
| 대량 추가발주 | 단가할인 가능하지만 납기와 기지용량 압박 |

지체상금이 있어도 시간이 되돌아오지 않는다. 손해배상 수입과 개통 지연에 따른 영업손실을 별도로 기록한다.

### 7.7 보증과 장기지원

- 보증기간과 보증 대상 부품.
- 목표 가용률·신뢰성·에너지 성능.
- 결함 반복 시 수정·부품교환·손해배상.
- 예비품 초기 공급과 재주문 납기.
- 소프트웨어·신호 인터페이스 지원.
- 제작사 철수·부도 시 기술자료와 대체부품 권리.

싼 차량이라도 부품지원이 끊기면 장기 가용률과 중고가치가 떨어진다.

## 8. 시스템 6 — 차량기지·유치·검사·정비

### 8.1 개통 필수 기능

| 기능 | 자체 확보 또는 계약 필요 |
|---|---|
| 유치·주박 | 비영업 편성과 예비·고장차량을 안전하게 수용 |
| 입출고 | 본선과 기지 사이 실제 진로와 처리능력 |
| 일상검사·청소 | 다음 영업일 출고 가능 상태 확보 |
| 고장대응·경정비 | 부품 교환과 응급수리 |
| 정기검사 | 법·사업자·제조사 기준에 따른 주기 작업 |
| 중정비 | 대차·차륜·주요기기 분해정비 또는 외부 위탁 |
| 구조·복구 | 사고차량 구원과 비상장비·예비품 |

자체 종합기지를 반드시 가져야 하는 것은 아니다. 유치·일상검사는 자체로 하고 중정비는 타사 공장에 위탁할 수 있다. 그러나 모든 기능의 용량·경로·계약이 확인되지 않으면 개통할 수 없다.

### 8.2 기지 등급

| 등급 | 포함기능 | 적합한 회사 | 한계 |
|---|---|---|---|
| D0 주박시설 | 유치·출고점검 최소 | 기존 정비망을 빌리는 지선 | 고장·정기검사 외부 의존 |
| D1 유치·일상검사기지 | 주박·청소·일상검사·간단수리 | 소형 신규노선 | 중정비 회송 필요 |
| D2 종합차량기지 | D1+정기검사·차륜전삭·부품창고 | 독립 도시철도 | 높은 초기비와 넓은 부지 |
| D3 공장급 | D2+대규모 분해·개조·여러 모델 중정비 | 대형 운영사·공동정비회사 | 수요 부족 시 고정비 과다 |

### 8.3 규모 계산

```text
기지수용편성 = 비첨두 유치편성
             + 예비편성
             + 검사대기·작업편성
             + 고장격리편성
             + 납품·증차 준비여유

유치선 유효길이 = 한 선에 넣을 편성 길이 합
                 + 편성 간 안전·작업 여유
                 + 양단 정지·출입 여유

필요 유치선수 = ceil(기지수용편성 / 선당 편성수)

일상검사 처리량 = 검사선수 × 교대수 × 선당 교대 처리편성
```

한 선에 두 편성을 넣으면 토지는 절약하지만 안쪽 편성을 꺼내기 위해 바깥 편성을 움직여야 한다. 게임은 `tandemBlockingPenalty`로 출고시간과 입환작업을 늘린다.

### 8.4 부지면적 초기 계획값

아래는 후보지 검색에 사용하는 게임 범위이며 법정 최소면적이 아니다. 검수등급·편성수·부지형상·복층화에 따라 다시 계산한다.

| 차량과 보유규모 | D1 권장 후보면적 | D2 권장 후보면적 |
|---|---:|---:|
| 60m급 소형 10~20편성 | 3만~7만㎡ | 5만~10만㎡ |
| 100~130m급 중형 20~35편성 | 7만~14만㎡ | 10만~20만㎡ |
| 160~220m급 대형 30~50편성 | 14만~25만㎡ | 20만~40만㎡ |

초기 상세 면적은 다음처럼 산정한다.

```text
유치구역 = 유치선수 × 유치선 유효길이 × 선로간격 × 배선·통로계수
건물구역 = 검수고 + 세척·전삭 + 창고 + 관제·직원 + 전력·환경시설
부대구역 = 도로·소방·배수·녹지·완충·장래확장
총면적 = 유치구역 + 건물구역 + 부대구역
```

지도 계층은 후보지의 실제 형상과 장애물을 전달하고, 시스템은 긴 평행선로와 건물이 실제로 들어가는지 검사한다. 같은 면적이라도 짧고 굽은 부지는 탈락할 수 있다.

### 8.5 위치 선택과 회사 손익

| 위치 | 회사 이익 | 회사 손실 |
|---|---|---|
| 종점 인접 | 회송·첫차·막차·배차가 유리 | 도심이면 토지·보상·확장비 증가 |
| 종점 밖 외곽 | 싼 토지와 확장성 | 인입선 건설과 평생 회송비 |
| 노선 중간 분기 | 양방향 첨두투입 | 분기·본선 슬롯·진로 충돌 |
| 도심 지하 | 짧은 회송과 지상 보존 | 구조·환기·방재비와 확장난이도 |
| 산업지역 | 주거민원과 기반시설이 상대적으로 유리 | 오염토·침수·기업이전 위험 |
| 기존 기지 공유 | 초기비와 개통기간 절감 | 타사 용량·정비 우선순위·사용료 의존 |
| 양단 분산 | 회송과 재해·장애 위험 감소 | 설비·인력과 지역협의 중복 |

### 8.6 회송비

```text
연간회송거리 = 편도거리 × 2 × 일일 입출고편성 × 운행일

연간회송비 = 연간회송거리 × 편성km 한계비용
           + 회송 승무·관제비
           + 본선 슬롯 혼잡비
```

30편성이 종점에서 5km 떨어진 기지에 매일 들어갔다 나오면 연간 109,500편성km다. 중형 도시철도 게임 임시값을 편성km당 1,200엔, 유인 회송비를 포함해 계산하면 직접손실은 연 약 1.51억 엔, 2% 실질할인율·30년 현재가치는 약 33.8억 엔이다. 인입선 건설·유지비는 별도다.

### 8.7 구조별 초기 배율

평탄한 외곽 지상기지 구조공사비를 1.00으로 둔 게임값이다. 토지·차량·인입선은 별도다.

| 형태 | 구조공사비 배율 | 일반 사업기간 |
|---|---:|---:|
| 외곽 평지 지상 | 1.00 | 4~7년 |
| 산업지역 지상 | 1.10~1.35 | 4~7년 |
| 상부 덮개 | 1.35~1.80 | 5~8년 |
| 반지하 | 1.80~2.80 | 5~9년 |
| 완전 지하 | 2.80~4.50 | 6~10년 |
| 기존기지 공유 | 0.15~0.60 | 2~5년 |
| 양단 분산 | 1.20~1.60 | 5~9년 |

### 8.8 한국에서 일본을 이해하는 사례

- 창동→진접: 노선 연장·외곽 대체기지·기존 도심부지 개발을 묶는 이전.
- 구로→광명: 기존 지역의 개발이익과 새 지역의 수용도는 별개이며 신역만으로 합의가 보장되지 않음.
- 신림선·우이신설선: 짧은 도심 경전철이 공원 지하에 기지를 넣어 회송과 지상단절을 줄이는 대신 확장성과 공사비를 포기.
- 일본 기바: 공원 지하 2층 기지로 토지 제약 해결.
- 요코하마 닛파: 기지 상부 장기 임대로 스포츠·상업시설과 자산수입 창출.
- 사가미하라: 기지 회송선 여객화와 지역역은 지역 요구일 뿐 자동 확정되지 않음.

## 9. 여섯 시스템을 연결하는 공통 경제

### 9.1 세 장부

| 장부 | 기록하는 것 |
|---|---|
| 플레이어 회사 | 출자·보조금·차입, 공사비, 차량비, 사용료, 운임, 운영·정비·회송비, 임대수입 |
| 국가·지자체 | 보조금·용지·공공시설비, 교통편익, 세수·개발가치, 정치·환경 비용 |
| 주민·이용자 | 접근시간·통행시간·혼잡·요금, 이주·소음·공사피해, 공원·역·지역개발 편익 |

사회적 B/C가 높아도 플레이어 현금흐름은 적자일 수 있고, 플레이어에게 수익이 나도 지자체가 사업을 승인하지 않을 수 있다.

### 9.2 회사 자금 흐름

```text
회사 총투자 = 회사부담 공사비 + 차량·기지·도입비
             + 건설 중 이자 + 개통 전 운영준비비
             - 보조금 - 공공부담금 - 자산처분수입

영업현금흐름 = 운임 + 광고·임대·부대사업
              - 전력·인력·정비·사용료·보험·세금
              - 회송·시설유지·대출상환
```

같은 사업이라도 시설 소유자, 운영권 기간, 보조율, 운임과 서비스 의무에 따라 플레이어 수익이 달라진다.

### 9.3 견적과 계약과 실제지출

- `estimate`: 조사 수준에 따른 예상 범위.
- `budget`: 사업을 위해 확보한 한도와 예비비.
- `contract`: 업체와 약속한 기준금액·변경조건.
- `committed`: 계약으로 이미 지급의무가 생긴 금액.
- `paid`: 실제 지급액.
- `forecastAtCompletion`: 현재 정보 기준 최종예상액.

예비비는 착공 순간 전액 지출하지 않는다. 사건과 설계변경이 발생할 때 사용한다.

## 10. 일정·지연·배속

### 10.1 모든 것이 같은 게임 시계를 쓴다

- 조사·승인·용지·공사·차량제작·기지·인력교육.
- 급여·전력·이자·보험·계약 만기.
- 검사주기·보증기간·부품납기.
- 주민협의·소송·정치지원.

배속은 기다림을 줄이지만 게임 내 개월 수와 금융비를 없애지 않는다.

### 10.2 임계경로

```text
개통일 = max(
  선로·역·설비 준비일,
  차량 최소편성 인수일,
  기지·정비 준비일,
  인력·운영계획 준비일,
  승인·계약 준비일
) + 통합시험·수정기간
```

본선이 먼저 끝나도 차량이나 기지가 늦으면 개통하지 못한다. 차량이 먼저 오면 보관·시험·보험비가 발생한다.

### 10.3 플레이어의 일정 대응

- 예비기간 확보.
- 공구 분할과 독립 작업면 추가.
- 대체 공급자·부품 사전확보.
- 부분개통 가능한 회차·기지 경로 설계.
- 야간·주말 만회공사와 추가비·안전위험 감수.
- 개통 연기 또는 서비스 축소.

## 12. 시나리오 모드 적용

### 12.1 기존망 유지

- 기존 철도는 외부망 또는 인수자산으로 시작한다.
- 플레이어는 직통·환승·시설공유 계약을 협상한다.
- 신도시 교통난, 병목 해소, 지선·연장, 노후차 교체와 기지 이전이 주요 과제가 된다.
- 기존 시설 규격 때문에 차량과 선형 자유도가 줄지만 초기 수요와 연결성이 높다.

### 12.2 철도·버스망 초기화

- 도로와 도시·인구·산업은 유지한다.
- 철도 규격과 네트워크를 처음부터 선택할 수 있다.
- 기존망 제약은 줄지만 최초 관제·기지·정비·기술도입비를 모두 부담한다.
- 개통 전 수입 공백을 버스·단계개통·자금조달로 버텨야 한다.

### 12.3 자금과 현실성 옵션

| 옵션 | 꺼지는 것 | 유지되는 것 |
|---|---|---|
| 무제한 자금 | 잔액 부족·파산 | 공기, 호환성, 기지·차량, 검사 |
| 즉시건설 샌드박스 | 공사·제작 대기 | 선택 시 호환성·용량 검사는 유지 가능 |
| 승인 간소화 | 정치·행정 대기 | 물리 공사와 시험 |
| 주민갈등 없음 | 협의·소송 사건 | 용지·구조·소음의 기술비용 |
| 완전 자유 | 모든 제한 선택 해제 | 사용자가 원하는 항목만 다시 켤 수 있음 |

## 14. 첫 구현 범위

처음부터 모든 철도 종류를 동시에 구현하지 않는다. 다음 한 사이클을 먼저 완성한다.

```text
일반 철제차륜 중형
+ 복선
+ 지상 또는 단순 고가
+ 상대식·섬식 일반역 3~5개

+ D1 유치·일상검사기지 1곳
+ 단순 운임·운영비
+ 실제 개월이 걸리는 공사·제작·시험
```

이 사이클이 저장·배속·회계까지 통과한 뒤 다음 순서로 확장한다.

1. 표준 지하와 지하역.
2. 대피·급행·종착 배선.
3. 차량 제작사 지연·보증·부분납품.
4. D2 종합기지와 외부 중정비 위탁.
5. 리니어 또는 AGT 한 종류.
6. 모노레일·대심도·복합환승.
7. LRT 전용궤도와 도로 상호작용.

## 16. 고정한 것과 아직 보정할 것

### 이 보고서에서 고정한 설계 원칙

- 일본을 기본 게임 국가로 하고 한국 사례로 설명한다.
- 가격 기준은 2026년 JPY다.
- 여섯 시스템이 모두 연결돼야 개통한다.
- 지도와 건설·경제 엔진을 분리한다.
- 구조, 주행 시스템, 선로 구성, 서비스와 정차 패턴을 분리한다.
- 차량 모델·편성·실물자산을 분리한다.
- 제작사, 시공사, 기지와 운영사를 분리한다.
- 회사·지자체·주민의 비용과 편익을 분리한다.
- 공사·제작·승인·운영비가 같은 게임 시계를 사용한다.
- 자료 부족을 건설 가능이나 비용 0으로 처리하지 않는다.

### 구현 전 또는 플레이테스트로 보정할 값

- 차량별 실제 정원·가속·제동·에너지와 정비주기.
- 역 승객밀도·계단·개찰·문별 처리량.

## 17. 최종 권고

다음 문서를 또 하나씩 늘리기보다 이 보고서를 상위 기준으로 삼고, 기존 상세 문서는 계산 근거와 사례집으로 유지한다.
