# B9-2 — 공사 물가상승·재원부족 대응 시스템

작성일: 2026-09-30
기준 통화·가격: 2026년 일본 엔(JPY), 공사비 지수 2026=100
담당: Codex

## 목적

장기 철도공사에서 정상적인 자재·노무비 상승과 예산을 다시 짜야 하는 급등 사건을 구분한다. 물가조정으로 남은 현금 약정을 늘릴 수 없을 때 공사를 무시하고 계속 진행하지 않고, 플레이어가 재원 대책을 결정하게 한다.

## 물가 모델

### 정상 물가

정상 물가는 사건이 아니라 매월 복리로 반영한다.

| 국가 | 보통 난이도 연간 게임 기준률 |
| --- | ---: |
| 일본 | 2.0% |
| 한국 | 2.3% |

쉬움은 기준률의 0.8배, 어려움은 1.25배다. 이는 2026년 실제 미래 물가를 예측한 값이 아니라 기존 기획의 정상 연 1~3% 범위 안에서 사용하는 게임 밸런스 기준이다.

계약 전에 상승한 지수는 새 공구 계약의 기준지수로 저장한다. 따라서 낙찰 전 상승분을 시공사가 소급 청구하지 않는다. 계약 후에는 이미 완성한 물량을 제외한 잔여 물량에만 적용한다.

### 급등 사건

`cost-inflation` 공사 사건은 정상 물가와 별개의 지수 충격이다.

| 심각도 | 추가 지수 |
| --- | ---: |
| 경미 | +1 |
| 보통 | +3 |
| 중대 | +6 |

사건이 발생한 월말에 지수 충격을 기록하고 다음 달 계약 정산부터 반영한다. 이미 그달 수행한 공정을 소급 취소하지 않는다. 사건 대응비는 긴급조달·가격고정·가치공학을 수행하는 직접 비용이며 지수 정산과 별도로 남는다.

## 계약별 부담

기존 A7 계약조건을 그대로 사용한다.

| 계약 방식 | 발주자 부담 | 시공사 흡수 |
| --- | ---: | ---: |
| 총액고정 | 10% | 90% |
| 물가연동 | 75% | 25% |
| 목표원가 | 50% | 50% |

발주자 부담분은 즉시 지급하지 않고 프로젝트 총사업비와 남은 건설 약정을 늘린다. 이후 월별 기성금으로 지급된다.

## 재원 부족 판정

매월 다음 순서로 처리한다.

1. 정상 공사비 지수 상승
2. 공구별 잔여 물량과 계약방식에 따른 정산 예정액 계산
3. 발주자의 가용현금으로 남은 약정을 증액할 수 있는지 검사
4. 가능하면 자동 정산
5. 불가능하면 `transitline.construction-funding-case/1` 생성
6. 해당 프로젝트의 공정 증가와 기성금 지급 정지

열린 재원부족 안건이 있으면 일반 공사 재개 명령으로 우회할 수 없다.

## 플레이어 선택

### 증액 예산 승인

- 부족액만큼 추가 예산을 확보한다.
- 관계기관·의회 재승인을 나타내는 임계 공정 2개월 지연이 발생한다.
- 시나리오의 추가 공사재원과 추가 공공재원을 따로 기록한다.

### 추가 출자

- 부족액만큼 스폰서 자본을 투입한다.
- 즉시 공사를 재개할 수 있다.
- 연 8% 기대수익률에 해당하는 향후 월 부담을 재무기록에 공개한다.
- 현재 운영 손익 엔진에서 실제 배당을 차감하는 기능은 다음 운영경제 단계의 범위다.

### 건설자금 차입

- 일본 연 3.5%, 한국 연 4.2%, 20년 원리금균등의 게임 조건을 사용한다.
- 1% 조달수수료를 포함해 부족액이 실제 순유입되도록 대출원금을 계산한다.
- 금융종결을 나타내는 임계 공정 1개월 지연이 발생한다.
- 대출잔액과 향후 월 상환액을 저장한다.
- 실제 개통 후 월별 원리금 차감은 운영 손익 루프에서 연결한다.

### 공사 중단

- 현금 조달과 물가정산을 하지 않는다.
- 프로젝트를 `suspended`로 바꾸고 기성금과 공정을 계속 0으로 둔다.
- 안건은 닫지 않으므로 나중에 세 가지 재원 대책 중 하나를 선택해 정산하고 기존 상태로 복귀할 수 있다.
