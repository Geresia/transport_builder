# 사이타마·치바·가나가와 건물 용도/층수 자료 조사 (2026-09-21)

도쿄 23구는 도쿄도 토지이용현황조사(건물 단위, BV_3 지상층, BV_4 지하층, CC BY 4.0)로 직장 계수와 지하 층수를 만들었다. 3개 현에 대응하는 자료를 찾았다. 이 목록의 라이선스와 속성은 검색 결과와 각 페이지 요약에 근거하며, 파일을 내려받아 필드를 확인하기 전까지는 **미검증**이다.

| 후보 | 단위 | 커버리지 | 라이선스 | 판단 |
|---|---|---|---|---|
| **PLATEAU 3D 도시모델** (G空間情報センター) | **건물 단위**(LOD1) | 도쿄 23구 + 26시 5정촌, 사이타마 48시정촌, 치바 6, 가나가와 8 | 상업 이용 가능(PLATEAU 사이트 정책). 데이터셋별 확인 필요 | **1순위.** 형식이 GeoPackage/GeoJSON/Shapefile이라 바로 읽을 수 있다. 사이타마시 페이지에서 용도(用途)는 확인, 층수·높이는 페이지에 명시 없음 |
| 가나가와현 도시계획기초조사 (제11회, 2020) | 소구역(GIS+CSV) 집계, 건물 단위 아님 | 현 전체 | CC BY 4.0 | 직장 계수의 검증용. 요코하마시는 소구역별 건물 용도별 동수·연면적 제공 |
| 사이타마현 도시계획기초조사 (2010/2015/2020) | 항목별 집계 | 현 전체 | 사이타마현 오픈데이터 이용규약 | 세부 단위 불명, 건물 현황 항목은 페이지에 안 나옴 |
| 치바현 | 조사 못 함 | - | - | 검색에서 근거를 찾지 못함 |

## 알게 된 것
- 3개 현 전체를 건물 단위로 채울 수 있는 공개 자료는 PLATEAU뿐이다. 그래도 치바(6곳)와 가나가와(8곳)는 일부 시만 커버한다.
- 도시계획기초조사 원본은 도쿄처럼 건물 단위가 아니라 집계 자료가 대부분이다. 직장 계수는 도쿄 계수를 이식하기보다 이 집계로 검증하는 편이 낫다.
- 지하 층수는 PLATEAU LOD1에 없을 가능성이 크다. 확인하지 않았다.

## 다음 단계
1. PLATEAU 사이타마시 GeoPackage 한 건을 받아 필드(`usage`, `storeysAboveGround`, `measuredHeight`)와 라이선스 표기를 확인한다.
2. 층수가 있으면 OSM 건물과 매칭해 사이타마시부터 직장 계수 적용 범위를 넓힌다.
3. 치바현은 별도 조사한다.
