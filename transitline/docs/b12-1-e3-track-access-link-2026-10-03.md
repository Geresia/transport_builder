# B12-1 E3 선로사용계약 연결

## 완료 범위

직통 서비스(`transitline.through-service/1`)와 B11-3 선로사용계약을 기존 ID로만 연결했다. 선로사용계약 스키마, 금액 계산, 운행량 산식은 확장하지 않았다.

- 직통 서비스 중단 시 연결된 활성 계약을 한 번만 중단한다.
- 중단된 직통 서비스를 재개하면 연결된 계약을 한 번만 활성화한다.
- 직통 서비스 종료 시 연결된 계약을 종료하고 경쟁사의 `accessCommitments`를 한 번만 해제한다.
- 선로사용계약을 직접 중단·재개·종료하거나 정산 중 만료해도 연결된 직통 서비스 상태가 같은 트랜잭션에서 따라간다.
- 여러 계약을 연결한 서비스는 모든 계약이 활성 상태일 때만 자동 재개한다.

## 불변 조건

- `dailyTrainKm`와 `trainsPerHour`는 E3 상태 연결 때문에 다시 계산하지 않는다.
- E3 상태 변경은 원장 항목을 추가하지 않는다.
- 같은 상태 변경을 반복하면 거절하며 계약 누계와 용량 예약을 중복 변경하지 않는다.
- 연결 계약이 없거나 유효하지 않으면 전체 트랜잭션을 롤백한다.
- 기존 B11-3 계약 상태 API로 발생한 변경도 동일한 연결 규칙을 적용한다.
