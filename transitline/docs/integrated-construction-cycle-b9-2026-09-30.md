# B9 — 통합 공사 진행·기성금 플레이 루프

작성일: 2026-09-30
담당: Codex

## 목적

공정표, 공사 사건, 실제 공정률, 기성금 지급, 차량 제작, 차량기지 공사를 하나의 월 진행 결과로 묶는다. 플레이어가 `+1개월` 또는 `+12개월`을 눌렀을 때 지도상의 지연과 경영 장부가 서로 다른 결과를 내지 않게 하는 것이 핵심이다.

## 발견한 기존 문제

- 통합 공정표와 공사 사건은 예상 개통월을 늦췄지만 실제 건설 프로젝트는 별도 월 계산으로 계속 진행했다.
- 임계 공정이 지연되어도 공정률과 기성금이 계속 올라가 프로젝트가 공정표보다 먼저 완성될 수 있었다.
- 오래 지연된 사업은 누적 경과월만으로 안전검사 3개월을 즉시 통과할 수 있었다.
- 차량 및 차량기지의 준공월 최종 지급액이 월 진행 반환값에 포함되지 않아 월별 지급 보고가 실제 현금 장부와 달라질 수 있었다.

## 구현 결과

### 통합 공정 게이트

`integratedConstructionProgressGate()`가 상세 공정표를 기존 가중 공정률의 상한으로 변환한다.

- 임계 작업에 `notBeforeFinishMonth`가 있으면 해당 단계의 마지막 지점 직전에서 공정률을 멈춘다.
- 공정률이 상한에 도달한 달에는 추가 공정과 기성금 지급이 모두 0이다.
- 차량, 차량기지, 토목, 시스템 등 선행 작업이 끝나지 않으면 종합시험 단계에 진입하지 못한다.
- 공구 입찰·낙찰 미완료와 중장비 작업면 부적합도 기존과 같이 월 진행을 막으며, 정지 원인을 보고서에 남긴다.

공사 사건은 월말에 발생하므로 새 사건의 지연 효과는 다음 달 공정부터 적용된다. 사건이 발생하기 전 그 달에 이미 수행된 공정을 소급 취소하지 않는 규칙이다.

### 실제 검사 기간

프로젝트가 공정률 100%에 도달하면 `inspectionElapsedMonths`를 0부터 별도로 센다. 과거 지연 개월 수와 관계없이 실제 검사 상태로 3개월을 보낸 뒤에만 사용 가능 상태가 된다.

### 월별 통합 보고서

새 계약은 `transitline.construction-cycle-report/1`이다. 매월 다음 정보를 고정 기록한다.

- 월 번호와 현금 전후·증감
- 토목 공사, 차량, 차량기지의 당월 지급액
- 프로젝트 상태·공정률·증분·기성금·정지 원인
- 임계 작업 지연과 시험 선행조건 상세
- 기준 개통월, 예상 개통월, 누적 지연, 공정표 차단 요소
- 신규 사건과 자동 대응된 사건 ID

보고서는 게임 저장본에 포함되며 다시 불러온 뒤에도 동일하게 유지된다. `ScenarioRuntime.report()`와 `constructionCycleReport()`에서도 읽을 수 있다.

### 플레이 화면

시나리오 패널에 `월별 통합 공정·기성금` 구역을 추가했다.

- 이번 달 공사 기성금
- 전체 차량·기지 지급액
- 현금 증감
- 기준 개통월과 현재 예상 개통월
- 누적 지연
- 진행 정지 사유와 임계 작업 상세
- 최근 6개월 공정률·공사비·지연 이력

`+1개월`과 `+12개월` 결과 메시지도 추정 문구가 아니라 실제 월별 통합 보고서의 지급액과 현금 증감을 표시한다.
