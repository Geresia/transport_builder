# 구조 형식별 물량·비용·공기 계산안

- 작성일: 2026-09-23 / 가격 기준: 2026년 / 통화: JPY
- 상태: 공개 기술자료 조사와 게임용 계산 설계. 실제 구조 안전 설계·공사 견적·인허가 판정을 대체하지 않는다.
- 관련: [철도 규격](railway-track-spec.md), [초기 수치표](railway-system-baseline-2026.md)
- 범위: 지상·성토·절토·고가·교량·지하의 토목 물량과 공정. 지도·원본 공간 데이터·운행 엔진은 수정하지 않는다.

## 1. 조사 결론과 근거의 한계

구조 형식만으로 고정된 km 단가와 공기를 부여하면 높이·깊이·지질·작업 조건의 차이를 충분히 표현하지 못한다. 게임에서는 **선형·구조 단면 → 물량 → 시공 작업 → 비용과 일정** 순서로 계산하는 안을 제안한다.

확인한 공개 자료:

- 국토교통성은 표준 품셈을 시공 실태 조사에 근거한 노무·재료·기계의 표준 소요량으로 설명한다. [표준 품셈 안내](https://www.mlit.go.jp/tec/constplan/sosei_constplan_tk_000024.html)
- 중국지방정비국 2025 수량산출요령의 토공 항목은 평균단면법 또는 3차원 모델을 통한 수량 산출을 설명한다. 일반 토공 물량 산정의 참고이며 철도 단가표로 전용하지 않는다. [2025 수량산출요령](https://www.cgr.mlit.go.jp/techserv/documents/03/r07_sanshutsu.pdf)
- JRTT는 도시 터널의 공법으로 개착·실드·도시 NATM 등을 구분하고, 산악 터널의 NATM을 설명한다. ‘지하’라는 구조 형식과 만드는 공법을 분리하는 근거다. [JRTT 터널](https://www.jrtt.go.jp/construction/technology/tunnel.html)
- JRTT는 교량을 형식과 재료에 따라 구분한다. 고가와 하천 교량은 공통 부재를 공유하되, 각 경간과 시공 조건을 따로 평가하도록 한다. [JRTT 교량](https://www.jrtt.go.jp/construction/technology/bridge.html)
- JRTT의 적산 표준 본편은 위탁 판매 자료이며 공개 변경표와 구분된다. 공개된 2026년 일반관리비율 변경표만으로 전체 공종 단가·품셈을 확보했다고 볼 수 없다. [자료 입수 안내](https://www.jrtt.go.jp/procurement/standards/obtain.html), [2026년 변경표](https://www.jrtt.go.jp/procurement/asset/25ada169c8b7b95fe562c230b8443ad8.pdf)

아래 식은 이 분류를 참고한 게임용 단순화 또는 기하학적 물량식이다. 숫자 예제는 계산 검산용이지 실제 일본 철도 표준 단면·법정 한계가 아니다. 실제 2026년 공종별 계약 단가와 생산성 전부를 검증한 상태는 아니다.

## 2. 기존 km당 가격과의 관계

초기 기준표의 지상 15 / 고가 60 / 지하 165억 엔/km는 그대로 **표준 조건의 초기 추정 패키지**로 보존한다. 이번 조사로 확인된 실제 일본 단가로 재분류하지 않는다.

각 자산·공종 범위는 아래 둘 중 하나로 평가한다.

1. `concept_package`: 상세 정보가 부족할 때 기존 길이×단가×계수를 사용. 가정과 미산정 항목을 표시한다.
2. `quantity_based`: 구조·작업 조건이 확보되면 실제 산출 물량×공종별 게임 단가로 대체한다.

같은 토목 범위에 두 결과를 더하지 않는다. 토목은 상세식, 신호는 패키지 같은 혼용은 가능하지만 범위가 겹치면 오류다. 상세 단가가 비어 있으면 계산법이 존재하더라도 `미산정`이지 0엔이 아니다.

기존 K 크기계수는 초기 패키지에만 적용한다. 실제 폭·터널 직경·부재 물량으로 크기 변화가 반영된 상세 견적에 K를 다시 곱하지 않는다. 상세 공법에서 지질별 공종과 생산성을 반영했다면 기존 ‘어려운 지반’ 계수도 같은 효과에 재적용하지 않는다.

## 3. 공통 입력과 비용 구조

### 필요한 입력

- 경로와 측점별 지표 고도, 레일 고도, 횡단 지형, 길이 기준.
- 차량·선로 수·선로 간격·동적 여유·작업 통로에 따른 필요한 구조 폭/내부 단면.
- 지질 층, 지하수, 지지층 정보와 조사 신뢰도. 모르면 임의의 정상 지반으로 확정하지 않는다.
- 건물·도로·하천·기존 시설, 교각 설치 불가 영역, 필요한 통과 공간, 사용 가능한 작업 부지.
- 시공사 역량, 장비·작업팀·작업면, 자재 공급, 작업 가능 시간과 계절 조건.
- 용지·작업장 사용 권리, 보상·이설 범위. 자동차 도로를 새로 만드는 기능은 포함하지 않는다.

노반 높이, 교량 상부 높이, 터널 중심 높이는 레일 높이와 다르다. 시설 단면의 두께·오프셋으로 각각 변환한 뒤 지형과 비교한다.

### 공통 비용식

```text
C_civil = Σ(공종 물량 Q_i × 공종 단가 p_i)
          + 범위가 분리된 현장 설치·철수 비용
          + 물량 항목에 포함되지 않은 임시 시설·환경·계측 비용
          + 실제 공기와 연동하는 별도 현장 유지 비용
```

v0.1 기준표와 연결할 때 p는 노무·재료·장비·시공사 간접비·이윤을 포함한 게임용 도급 단가를 기본으로 한다. 원재료 가격만 쓰는 상세 원가 모델을 선택하면 노무·장비·간접비를 따로 계산하되, 이미 포함된 비용을 재가산하지 않는다. 단가마다 `unit`, `priceBasis`, `includedScopes`, `excludedScopes`를 저장한다.

설계·발주자 사업관리·시험·예비비는 기존 기준표의 별도 항목에 연결한다. 용지·금융·세금·역·차량·철도 설비는 해당 패키지에 연결하며 C_civil과 중복시키지 않는다.

## 4. 지표면 지상 — 면적·층 두께·배수 길이

토공 높이가 작아도 공사량이 0이 되지는 않는다.

```text
정지 면적 A = 구조 폭 W × 수평 경로 길이 L
노반 재료량 V = 층별 면적 × 해당 층 두께의 합
배수·방호 물량 = 실제로 설치할 측면별 길이의 합
지반 개량량 = 처리 면적 × 처리 깊이  # 해당 공법이 체적 기준일 때
```

굴착·치환·다짐·배수·방호를 작업으로 분리한다. 지반 개량은 공법에 따라 면적·체적·개량체 길이 등 산출 단위를 바꾼다. 도로와 충돌하면 교차 허용 여부 및 철도 입체화 대안을 확인하고 도로를 자동 삭제하지 않는다.

주요 일정은 작업장 준비 → 지반 처리 → 노반 층별 시공·검사 → 배수·방호 → 궤도 인도다. 구간별 시공이 가능하므로 전체 노반이 끝날 때까지 모든 후속 작업을 무조건 대기시키지 않는다.

## 5. 성토 — 흙을 쌓는 높이와 사면 폭

성토 높이 h는 지표에서 **완성 토공 상단**까지다. 레일 높이에서 궤도·노반 상부층을 제외해야 한다.

평탄한 원지반, 일정한 상단 폭 b, 양측 동일 사면의 단순 단면에서 사면비 m을 ‘수직 1m당 수평 m m’로 정의하면:

```text
성토 단면적 A = b×h + m×h²
지표 점유 폭 W = b + 2×m×h
사면 면적 = 2×h×sqrt(1+m²)×L  # 일정 단면 구간
토량 V ≈ Σ((A_i + A_(i+1))/2 × ΔL_i)
```

마지막 식은 평균단면법이다. 높이·폭·지형 변화가 큰 곳은 측점을 추가한다. 절토/성토가 바뀌는 지점도 분리한다. 불규칙 지형은 실제 횡단면을 사용하며 위 사다리꼴을 무조건 적용하지 않는다.

### 예제: 같은 1km라도 높이로 물량이 달라진다

가정: b=10m, m=1.5, 길이 1,000m, 일정 높이. 안전성이 확인된 실제 표준 단면이라는 뜻은 아니다.

| 높이 | 단면적 | 완성 성토량 | 지표 점유 폭 |
|---|---:|---:|---:|
| 3m | 43.5m² | 43,500m³ | 19m |
| 6m | 114m² | 114,000m³ | 28m |

높이는 2배지만 성토량은 약 2.62배다. 점유 면적에는 여기에 배수·점검·작업 공간이 더해진다. **총공사비가 정확히 2.62배라는 뜻은 아니다.**

성토비에는 재료 조달, 운반, 층별 포설·다짐, 사면 보호, 배수, 지반 개량, 침하 관측 등이 들어간다. 좁은 부지에서는 옹벽·보강토 대안을 비교한다. 옹벽을 선택하면 사면 토량과 점유 폭을 다시 산출하고 옹벽 비용만 기존 사면에 더하지 않는다.

## 6. 절토 — 파낸 흙의 처리까지 계산

평탄한 원지반에서 아래쪽 완성 폭 b, 깊이 d, 양측 사면비 m인 단순 절토는 `A=b×d+m×d²`로 물량을 구할 수 있다. 실제 지형과 벤치·암반 구간은 별도 단면으로 나눈다.

```text
C_cut = 토질별 굴착량×굴착 단가
        + 운반량×운반 거리별 단가 + 외부 반출·처리비
        + 사면/옹벽 + 배수 + 필요한 보강·계측
```

굴착한 원지반 토량, 운반 중 느슨한 토량, 다짐 후 성토량을 같은 m³라고 그대로 상계하지 않는다. 변환 계수는 조사 결과와 공법 프로필에 둔다.

게임 수지 계산: `재사용 가능 완성 성토량 = 적합한 원지반 굴착량 × 재사용률 × 다짐 체적 변환계수`. 이 양을 성토 수요에 배분하고 부족량을 구매한다. 남은 물량은 대응 상태로 환산하여 보관·반출한다. 토질 적합성, 공정 시점, 임시 적치 공간과 운반 거리를 함께 검사한다.

절토량과 성토량이 같다고 비용이 상쇄되거나 음수가 되지 않는다. 재사용해도 굴착·운반·다짐 작업은 남는다. 암반·오염 의심토는 일반 성토재로 자동 전환하지 않는다.

## 7. 고가 — 경간·교각·기초·상부 구조

균일 경간의 독립된 단순교 예비 배치에서는:

```text
경간 수 n = ceil(전체 길이 / 해당 형식의 허용 경간)
실제 균등 배치 경간 = 전체 길이 / n
지점 수 = n + 1
양 끝 교대 2개인 경우 내부 교각 수 = n - 1
```

실제 배치는 도로·건물·기존 시설 때문에 달라진다. 라멘 고가교 등은 전용 구조 템플릿을 사용하고 위 지점 공식을 강제하지 않는다. 인접 자산과 공유하는 교각·교대는 고유 ID로 한 번만 계상한다.

```text
C_elevated = Σ기초 + Σ교각/교대 + Σ경간 상부 구조
             + 해당 형식의 받침·접속부 + 가설 작업 + 방호·배수
말뚝 길이 합 = Σ(기초별 말뚝 개수 × 말뚝 길이)
교각 콘크리트량 = Σ(단면적 × 실제 기둥 높이) + 캡 등의 부재량
```

- 단순 예제: 1,000m를 25m 경간으로 나누면 40경간, 41지점, 양 끝 교대 2개와 내부 교각 39개다. 도시 전체에서 기초가 반드시 41개라는 일반 규칙은 아니다.
- 높이가 커지면 기둥 재료뿐 아니라 안정성·기초·시공 접근 조건도 달라진다.
- 지지층이 깊으면 말뚝 물량과 시공 기간이 달라진다. 말뚝 길이를 지상 교각 높이로 대신 계산하지 않는다.
- 차체 폭·선로 수가 커지면 구조 폭과 하중 조건이 변한다. 차량 폭만으로 안전한 부재 치수를 자동 산출하지 않는다.
- 부재 크기는 하중·경간·높이·지반 조건을 지원하는 게임용 구조 템플릿에서 선택한다. 지원 범위를 벗어나면 재설계/견적 미지원으로 남긴다.

기간은 기초조, 교각조, 거더 제작·운반·가설조의 선행 관계로 계산한다. 공장에서 거더를 제작하는 동안 현장 기초를 병행할 수 있지만, 지지 구조가 준비되기 전 가설할 수 없다.

## 8. 교량 — 장애물을 건너는 특별 조건

고가와 같은 기초·하부·상부 구조 모델을 사용한다. ‘고가 비용 + 교량 비용’으로 중복 산정하지 않는다.

추가 입력은 횡단 폭, 교각 설치 허용 영역, 수면·도로 등의 통과 공간, 기초 조건, 구조 형식, 작업 가능 계절·시간, 자재 운반과 가설 접근이다.

- 긴 경간으로 교각 수를 줄여도 상부 구조와 가설 부담이 커질 수 있으므로 반드시 싸지는 것은 아니다.
- 수중 기초·가물막이·작업대·수상 장비가 필요하면 별도 작업 물량으로 계산한다.
- 하천 조건 등으로 공사할 수 없는 기간은 작업 달력으로 처리한다. 연중 평균 생산성만 낮춰 금지 기간에도 작업하는 오류를 피한다.
- 통과 공간은 레일 높이가 아니라 거더 하단 등 실제 장애물 최저점과 비교한다.

특수 교량에 필요한 구조 템플릿·단가가 없으면 기존 고가 단가의 임의 배수로 확정 견적을 만들지 않는다.

## 9. 지하 — 깊이만이 아니라 단면·공법·지반

### 9.1 공통 높이·공간 정의

원형 터널에서 토피는 `지표 고도 - (터널 중심 고도 + 굴착 직경/2)`다. 레일 깊이와 같지 않다. 지하수 수두 역시 터널 위치와 지하수 고도를 비교해서 계산한다. 깊이만으로 일정한 비용 배수를 정하지 않는다.

필요 내부 단면은 차량 동적 여유, 선로 간격, 집전 설비, 통로·피난·배수 공간 등을 함께 수용해야 한다. 실제 법정 이격값은 이번 조사에서 확정하지 않았다.

### 9.2 개착

직사각형 작업 공간의 단순 예비 물량:

```text
굴착량 = 작업 폭 × 굴착 깊이 × 길이
흙막이 면적 = 흙막이를 설치하는 둘레 길이 × 설치 깊이
구조체 콘크리트량 = 외곽 체적 - 내부 빈 공간 체적
```

흙막이 설치 깊이는 바닥 아래 근입부를 포함할 수 있으므로 굴착 깊이와 구분한다. 사면 굴착, 불규칙 형상, 여러 내부 공간은 각 단면으로 다시 산출한다.

비용은 흙막이·지보, 지장물 처리, 굴착·반출, 구조체·방수, 되메우기, 작업 전 점유 상태로의 복구, 임시 배수 등으로 구성한다. 도로 복구는 기존 기능을 돌려놓는 공사 범위이며 도로망을 새로 설계하는 게임 기능이 아니다. 작업장·임시 점유 허용 여부를 먼저 확인한다.

### 9.3 실드

```text
굴착량 = Σ(π/4 × 굴착 직경² × 각 굴착 터널 길이)
복공 기하 체적 = Σ(π/4 × (복공 외경² - 내경²) × 길이)
링 수 = 터널별 ceil(복공 길이 / 링 폭)의 합
C_shield = 굴착기 조달·반입·조립·철수
           + 작업구 + 굴진·배토 + 세그먼트·조립·주입
           + 지반 대응·연락 통로·계측·배수 등의 해당 작업
```

세그먼트는 ‘링 패키지 가격’ 또는 부재별 가격 중 하나를 쓴다. 위 체적을 단가에 곱한 뒤 같은 링 가격을 또 더하지 않는다. 굴착기 조달비는 구매·임대·다른 공구 재사용 조건을 구분한다. 재사용이어도 운송·개조·재조립 비용은 남는다.

단선 터널 2개라면 각 터널 길이를 합산한다. 복선 터널 1개라면 큰 단면 1개를 계산한다. ‘복선’이라는 이유로 큰 터널 체적을 다시 두 배 하지 않는다.

예제: 각각 1km인 터널 2개에서 굴착 직경이 6m일 때 약 56,549m³, 7m일 때 약 76,969m³다. 직경 증가로 굴착량이 약 36.1% 늘지만 기계·작업구·복공비도 달라지므로 총비용에 같은 비율을 강제하지 않는다. 두 직경 모두 실제 차량 수용 가능성이 검증된 설계라는 뜻은 아니다.

작업구 수는 길이를 일정 수로 나눈 자동값이 아니라 발진·도달 위치, 작업 부지, 기계 이동 계획으로 결정한다. 연락 통로와 피난 시설도 지원하는 설계 프로필에 따라 요구량을 산출한다. 역을 작업구로 활용하면 해당 구조물 공사비와 준비 시점을 공유한다.

### 9.4 산악 터널·NATM

암반·토질 구간별 굴착 체적, 굴착 단계, 록볼트 수·길이, 숏크리트 체적, 강지보, 복공, 보조 공법·배수·계측을 산출한다. 물량과 생산성은 지질 구간마다 다르게 적용한다.

단순 게임식은 `Σ(지질별 길이 × 해당 굴착·지보 패키지 단가) + 갱구·접근·설비·특수 대응`으로 둘 수 있다. 이 패키지는 구조별 km 단가보다 세분화된 공종 묶음이며, 지보를 별도 상세 산출하면 패키지에서 같은 범위를 제외한다.

도시에서도 조건에 따라 다른 공법이 사용될 수 있으므로 ‘산이면 NATM, 도시면 실드’라는 무조건 선택 규칙은 두지 않는다. 공법 상세·장비·시공사 자원은 이후 공법 명세에서 다룬다.

## 10. 구조 전환부와 복합 구간

- 지상↔고가·지하 연결부도 실제 길이와 물량을 가진다. 전환부가 추가될 때 주변 구간 길이를 다시 분할하여 중복 합산을 막는다.
- 일정 경사만 가정한 연결 수평길이는 `높이 차 / 경사비`다. 예: 20m와 25‰이면 800m. 종곡선·접속 조건은 추가이고 이 경사가 법정 허용치라는 뜻은 아니다.
- 터널 입구·개착 접근부·옹벽·배수·침수 대응을 포함할 범위를 명시한다.
- 한 선로는 고가, 다른 선로는 지상인 구간이나 분기부는 ‘복선 전체 같은 구조’로 처리하지 않고 실제 자산별로 계산한다.

## 11. 공기 계산 — 작업망과 자원·달력

```text
필요 작업일 = 물량 / (작업팀당 일 생산성 × 배정팀 수 × 작업조건 효율)
착수일 = 선행 작업 인도, 자원 확보, 부지·작업 승인 이후의 작업 가능일
완료일 = 착수일부터 작업 가능 달력에 필요한 작업일을 배치한 날짜
```

위 생산성 식은 독립된 작업면에 팀을 배정할 수 있을 때만 사용한다. 굴진면 하나에 팀 두 개를 붙였다고 두 배 전진시키지 않는다. 배토·자재 반입·양생 등이 병목이면 전체 작업 주기에서 가장 제한적인 조건을 반영한다.

- 양생·침하 관측·승인 대기는 물량/생산성에 넣지 않는 별도 경과시간 작업이다.
- 실드는 발진구 준비와 기계 제조·조립 후 굴진이 시작된다. 두 굴진기를 쓰면 독립 작업면·장비비·작업장도 필요하다.
- 고가는 기초→교각→가설을 위치별로 연결하고, 제작은 별도 공장 자원을 사용한다.
- 성토는 토사 공급·다짐·검사·필요한 관측의 순서, 절토는 반출·사면 보강과 굴착의 순서를 연결한다.
- 공기 연장은 별도 현장 유지비, 장비 임대, 금융비용에 영향을 준다. 같은 영향을 ‘지연 벌금’과 실제 원가로 중복 부과하지 않는다. 계약상 지체상금은 별도 계약 항목이다.

소규모 검산 예제: 토량 43,500m³, 1팀 500m³/작업일, 독립 작업면 2개·팀 2개이면 43.5작업일이다. 월 20작업일인 단순 달력에서는 약 2.175개월의 해당 토공 작업량이다. 준비·조사·관측·다른 공종을 제외한 예제이며 실제 생산성·전체 공기로 제시하지 않는다.

## 12. 게임 입력·출력과 검증

지도·데이터 담당은 공간 형상·고도·교차·조사 정보를 제공하고, 시스템은 그 입력으로 물량·비용·작업망을 계산한다. 이번 설계에서 지도 추출 기능을 구현하지 않는다.

반환할 결과:

- 구조별 자산 ID와 공종 물량, 단위, 수량 산출 근거.
- 범위별 초기 추정/물량 산출 여부, 사용 단가·조건·버전.
- 계산 완료 금액과 미산정 항목, 불확실성 범위 및 원인.
- 필요한 전문업체·장비·작업장·인허가 조건.
- 선행 관계, 필요한 자원, 작업 달력, 예상 완료 및 개통 영향.
- 구조 폭·경사·작업 부지·지반 등에 대한 부적합/자료 부족 사유. 금액이 산출돼도 구조 안전 통과를 의미하지 않음.

최소 검증:

1. 3m/6m 성토 예제의 물량·점유 폭이 위 값과 일치한다.
2. 높이 0의 단면은 성토량 0이지만 노반·배수 공사까지 자동 무료가 되지 않는다.
3. 절토/성토 경계와 급격한 지형 변화에서 측점 추가 및 분리 산출을 한다.
4. 흙의 상태·재사용률·운반 거리·적치 시점을 무시한 토량 상계를 거부한다.
5. 같은 고가 지점·공유 작업구·역 박스는 한 번만 계상한다.
6. 단선 터널 2개와 복선 터널 1개의 단면·길이를 구분한다.
7. 굴착 직경과 내부 유효 직경, 레일 깊이와 토피를 구분한다.
8. 상세 물량 가격과 기존 km 패키지·크기계수·지질계수를 같은 효과에 중복 적용하지 않는다.
9. 길이 0·음수 직경·내경이 외경보다 큰 경우 등 입력 오류를 거절한다.
10. 미조사 지반·미지원 단가·미확보 작업장은 자동 0원/즉시 완료가 되지 않는다.
11. 동일 장비·팀을 동시에 중복 사용하거나 작업 금지일에 공사하지 않는다.
12. 구조가 완료되어도 차량·전력·신호·역·기지·시험 조건이 남으면 개통하지 않는다.

## 13. 후속 수치화 범위

이번 결과는 구조별 계산법과 산출 경계의 조사·설계안이다. 기존 2026 JPY 패키지 값은 변경하지 않았다. 상세 물량 모드에 필요한 토공 단가, 말뚝·교각·거더 템플릿, 터널 공법별 단가·생산성은 출처 또는 게임 가정임을 명시하여 별도 버전으로 채워야 한다. 자료 판매본은 구매하지 않았으며 자료의 완전한 확보나 엔진 구현 완료를 주장하지 않는다.
