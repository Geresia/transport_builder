# 건설·경제·사업수주 엔진 구현 보고서

- 기준일: 2026-09-25
- 통화·가격 기준: 2026년 JPY
- 국가 프로필: 일본, 대한민국
- 실행 화면: `engine/management.html`
- 테스트 명령: `npm test`

## 구현 결과

로드맵 I0~I8을 하나의 실행 가능한 기준 시나리오로 연결했다.

```text
공공 O&M 또는 철도 DBO 공고
→ 공고문·참가자격·요구규모 확인
→ 유료 조사
→ P50/P90 사업성 검토와 Bid/No-Bid 투자심의
→ 최소 노선·역 규모를 충족한 기술계획과 가격제안 제출
→ 플레이어·경쟁사 입찰 및 준비비·입찰보증 반영
→ 적격·최소기술·종합평가
→ 단독응찰 적정성심사 또는 우선협상자 선정
→ 협상·계약, 결렬 시 차순위 전환 또는 조건조정·재공고
→ 수주 사업만 실시계획 승인·사업화
→ 노선 견적·건설계약·기성지급
→ 차량 발주·제작·시험·인수
→ 차량기지 확보
→ 개통 준비 판정
→ 30일 및 1년 영업운행
→ 운임·공공대가·KPI·비용·손익 정산
```

## I0 운행 엔진 안정화

- 렌더링 프레임과 분리된 1초 고정 시뮬레이션 틱.
- 큰 시간 간격에서도 여러 구간, 정차, 종착 회차를 모두 소비하는 열차 이동.
- 24시간 기준 요일 전환과 자정 이후 영업시간대 처리.
- 노선 중단을 경로 그래프와 배차에 반영.
- 열차 방향과 목적역 방향이 일치할 때만 승차.
- 총 여행시간과 환승 대기시간을 분리해 포기 시각 계산.
- 노선 삭제 시 승객을 가까운 역에 내리고 경로를 다시 계산.
- 출발지와 목적지가 같은 경우 빈 대중교통 경로를 안전하게 처리.
- 이진 힙 Dijkstra와 그래프별 경로 캐시. 250역 합성 그래프 10,000회 성능을 매 테스트에서 기록하고 5초 예산을 검사한다.

## I1 공통 커널

- `SimulationClock`: 날짜, 분 단위 시각, 예약 사건.
- `DeterministicRng`: 저장 가능한 고정 시드 난수.
- `EventLog`: 원인과 결과를 가진 시간순 사건.
- `Ledger`: 현금 거래, 확정 의무, 기성 지급, 가용현금 검증.
- 원자적 경영 명령: 실패 시 해당 명령 전 상태로 복구.
- 스키마 버전 1 저장·복원. 미래 버전은 오류로 거절.

핵심 불변식은 다음과 같다.

```text
기초현금 + 모든 원장 금액 = 현재현금
현재현금 - 미지급 확정의무 = 가용현금
실패한 명령 = 현금·계약·자산 부분 변경 없음
같은 저장본 + 같은 명령 = 같은 난수 사건과 결과
```

## I2 수요·시설·서비스 분리

`DemandNode`, `AccessLink`, `Station`, `Platform`, `TrackSegment`,
`ServiceLine`, `VehicleUnit`, `ExternalNetwork`를 서로 다른 컬렉션으로
관리한다. CityPack 수요점은 역을 자동 생성하지 않고 수요 노드로
변환된다. 한 수요 노드는 여러 역에 각기 다른 보행시간으로 연결할 수
있다.

지도 모듈은 `PlanGeometry`를 전달하고 경영 엔진은 다음을 반환한다.

- 건설 가능, 조건부, 불가 판정.
- 위반사항과 결측 입력.
- P50 중심 비용 범위와 기간 범위.
- 차량·선로 기술 프로필 호환성.

## I3 사업수주

- 공개정보와 2단계 유료 조사.
- P50/P90 원가와 수요 범위.
- 제안 준비비와 입찰보증 한도.
- 지속 객체 경쟁사 5개와 각 회사의 현금, 평판, 역량, 수주잔량, 전략.
- 적격성에 따른 불참과 회사별 Bid/No-Bid 난수 판단.
- 최저 기술점 통과 후 기술 55%, 가격 45% 종합평가.
- 무응찰, 기술 전원탈락, 단독응찰 적정성심사, 우선협상, 차순위 전환, 재공고 상태.
- 협상 종료·탈락·재공고 때 회사별 입찰용량과 플레이어 입찰보증 한도를 정확히 해제.
- 지도 시나리오에서는 공고 최소 노선·역 규모를 검사하고, 최종 수주 전 계획 승인과 공사 생성을 차단.
- 고정 서비스대가와 정시율 KPI 보너스·감액 계약.

## I4 건설

지원 구조는 지상, 고가, 개착, 실드, 대심도, 교량, 성토, 절토다.
구조물 km와 역 공사비를 별도로 계산하며 시스템, 설계관리,
통합시험, 예비비를 분리한다. 일본과 한국은 동일 물리 노선에서도
국가 프로필의 비용·승인기간·갈등 지연계수에 따라 결과가 다르다.

공사는 `estimated → contracted → underConstruction → inspection → available`
상태로 진행한다. 계약금과 월 기성금이 실제 원장에 기록되고, 현금이
부족하면 상태와 돈이 함께 원상복구된다. 지연 사건은 저장 가능한
난수로 발생한다. 취소한 사업의 기지급액은 매몰비용으로 남는다.

## I5 차량과 차량기지

- 소형·중형·대형 철제차륜, AGT, 모노레일, 리니어 메트로 카탈로그.

- 계약금, 설계, 제작, 공장시험, 운송, 노선시험, 인수 단계.
- 편성별 상태, 누적거리, 검사거리.
- D1 기지의 유치용량, 일상검사 처리량, 입출고경로, 외부 중정비.
- 종점형·교외형·원격형·공유형 위치전략의 토지가격, 회송거리,
  첫차 준비시간, 주민갈등 차이.
- 차량·선로 방식, 편성량수, 승강장 길이 호환성 검사.
- 지도 `DepotSiteGeometry`에서 부지면적·접속거리·경사·건물·주거노출을 받아 후보별 P50/P90와 회송 OPEX 계산.
- 지상·상부덮개·반지하·지하·확장·공유 구조, 환경저감 3단계와 지역환원 5종.
- 주민 반대압력, 지자체 지지도, 국가·지자체·사업자 비용분담 협상.
- 협상 부결 시 설계·지역대책 수정과 재협상, 협상 전 착공 차단.

- 완성되지 않은 기지와 입출고선은 본선·차량이 준비돼도 개통 불가.

## 검증 결과

2026-09-26 기준 `npm test` 결과는 143개 테스트 전부 통과다. 테스트에는
기존 수심·OD·공간인덱스 검증, E-01~E-07 회귀, 원장과 저장, 한일 비교,
입찰, 단독응찰·차순위·재공고·보증해제, 공사·차량·기지·개통·30일 운영, 1년 저장복원 일치, 지도계획
버전·원자적 개통·접근 링크·실운행 정산·통합 저장·시나리오가 포함된다.
차량기지 후보지 공간계약과 입지·비용·회송·지역협의·다년 공사도 같은
전체 회귀검증에 포함된다.
Claude 지도 변환기의 실제 `PlanGeometry` 출력과 결측자료 출력도 같은 계약
테스트에서 경영 엔진에 직접 접수한다. 지도 화면의 기본 시나리오 런타임은
계획선이 즉시 운행되지 않음, 공사 중단·재개, 차량·기지 준비, 원자적 개통,
통합 저장·복원을 추가로 검증한다.

40km·7역 실드 지하 기준선은 일본·한국과 AGT·리니어·중형·대형철도의
비용 차이, 2개 병행 공구의 공기, 최소 14편성, 난이도별 예산 가능 여부를
고정 회귀테스트로 검증한다. 결과표는
[40km·7역 엔진 보정 결과](engine-calibration-40km-7-stations-2026.md)에 있다.
