# B19 신도시·철도 연계 설계 메모

## 목적

신도시를 단순한 수요 수치 증가가 아니라, 입주·택지 공급·재원 분담·교통 대책이 시간차를 두고 맞물리는 장기 사업으로 만든다. 플레이어는 교통회사 사장으로서 철도 수주, 버스 선행 운행, 개발권 연계, 운영 계약을 선택한다.

## 한국·일본 시나리오 프로필

| 항목 | 한국형 공공 신도시 | 일본형 연선·토지구획정리 신도시 |
| --- | --- | --- |
| 시작 | 공공 택지·광역교통 계획 발표 | 토지구획정리·역세권 개발·지자체 협의 |
| 철도 사업화 | 수요 검토, 타당성, 국비·지방비, 발주 | 수요·비용·사업방식·부담 주체 조정, 철도회사·제3섹터·지자체 참여 |
| 플레이어 기회 | 버스 선행, 철도 운영·건설 수주 | 철도 운영·건설 수주, 개발권·역세권 사업 연계, 공동 출자 |
| 주요 위험 | 예산·보상·민원·개통 지연 | 택지 공급·입주율·지자체 분담·운영 적자·사업 주체 합의 지연 |

이는 실제 제도와 사례를 게임 규칙으로 압축한 시나리오 프로필이며, 모든 일본 사업이 같은 재원 구조를 갖는다는 뜻은 아니다.

## 상태 흐름

`발표 → 토지정리·인허가 → 기반시설 공사 → 단계 입주 → 교통 대책 재검토 → 철도/버스 운영 → 포화·증설 또는 사업 축소`

각 단계에는 예정 인구와 실제 입주율이 따로 존재한다. 예정 인구만으로 수익이나 철도 타당성을 확정하지 않는다.

## 플레이어 결정

1. 버스 선행, BRT, 철도 연장 예약, 신설 철도 중 제안안을 낸다.
2. 정부·지자체·개발사업자와 건설비, 차량기지 부지, 역세권 권리, 운영 적자 보전 조건을 협상한다.
3. 입주 단계에 맞춰 증차·증편·추가 출입구·환승시설을 투자하거나 보류한다.
4. 분양·입주 지연, 주민의 역 추가 요구, 재원 분쟁, 경쟁사 제안에 대응한다.

## 시스템 입력과 결과

입력: 개발 단계, 택지 공급량, 실제 입주율, 고용·상업 비율, 도로 완성도, 공공 분담, 개발사업자 조건, 노선·역·차량기지 계획.

결과: 시간대별 OD 수요, 버스/철도 혼잡, 운임 수입, 보조금·개발권 수입, 공사와 개통의 지연 위험, 지가·고용·추가 개발의 피드백.

## 구현 순서

- B19-1: `NewTownDevelopment` 상태와 단계별 입주·토지공급·개발 계약의 결정론적 저장/복원.
- B19-2: B15 수요 엔진에 개발 단계·실입주율을 입력으로 연결.
- B19-3: 철도/버스 교통대책 제안, 지자체·개발사업자 분담 계약, 사업화 조건.
- B19-4: 입주 지연·분양 부진·역 추가 요구·재원 분쟁 사건과 B14/B18 연계.
- B19-5: 한국형/일본형 시나리오 팩과 30년 캠페인(B20) 연결.

## 금지 규칙

- 계획 인구를 실제 승객·수익으로 즉시 전환하지 않는다.
- 철도 개통만으로 토지가 자동 개발되거나 지가가 자동 상승하지 않는다.
- 지도 데이터가 없는 토지 소유·지하 조건·입주율을 확정 사실로 만들지 않는다.
