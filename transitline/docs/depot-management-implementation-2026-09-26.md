# 차량기지 입지·경제·협의·건설 엔진 구현 보고서

- 기준일: 2026-09-26
- 통화·가격 기준: 2026년 JPY
- 담당 경계: 경영·건설·운영 계산
- 공간 입력: `transitline.depot-site-geometry/1`
- 설계 근거: [차량기지 건설·지역협의 시스템](railway-depot-system.md)

## 구현 결과

차량기지는 더 이상 편성 수만 입력하면 즉시 확보되는 시설이 아니다.

```text
운행계획으로 필요편성·검사량 계산
→ 지도 후보지 공간정보 접수
→ 면적·경사·본선접속 탈락조건 검사
→ 복수 후보 CAPEX·회송 OPEX·수용성 비교
→ 구조·환경저감·지역환원 선택
→ 국가·지자체·사업자 비용분담 협상
→ 협상 성립 후 건설계약과 계약금 지급
→ 월별 기성지급·지연·시험
→ 기지와 입출고선이 완성돼야 개통 가능
```

## 공간정보와 경영계산의 경계

지도 모듈은 다음 사실만 전달한다.

- 부지 면적과 위치
- 본선 접속선과 종점까지 거리
- 경사, 건물·도로·수역 교차
- 주거지 거리와 주변 건물밀도
- 기존 철도시설 재사용 가능성
- 자료품질과 결측항목

경영 엔진이 다음 값을 계산한다.

- 필요한 기지면적과 수용 가능 여부
- 토지·토목·검수설비·인입선·이전비
- 환경저감·지역환원 비용
- P50·P90 사업비와 공사기간
- 주민 반대압력과 지자체 지지도
- 연간 회송거리·회송비·첫차 준비시간
- 운영·비용·수용성·확장성·재해·부대수입 점수

지도 결측값은 0으로 바꾸지 않는다. `unknown[]`과
`constraintUnknown[]`의 개수 및 `dataQuality`를 예비비와 기간 불확실성에
반영한다. 다만 부지면적·본선연결·허용경사처럼 계약에 필수인 조건이
미확정이면 `conditional`로 남아 협상은 가능해도 건설계약은 체결할 수 없다.

## 필수면적

```text
편성길이 = 차량 수 × 차량계열별 승강장 길이

유치면적 = 필요편성 × (1,200㎡ + 편성길이 × 12㎡/m)
검수·지원면적 = 20,000㎡ + 일일검사량 × 5,000㎡
필수면적 = (유치면적 + 검수·지원면적) × 1.15
```

같은 14편성이라도 3량 AGT보다 4량 중형철도가 더 긴 유치선과 넓은
면적을 요구한다. 지하·공유형은 입체화와 기존시설 활용으로 토지면적을
줄이지만 증설성과 운영독립성이 낮아진다.

## 후보지 유형

공간정보와 선택 구조를 조합해 다음 유형으로 판정한다.

| 유형 | 핵심 특성 |
|---|---|
| 종점 인접 | 회송과 첫차 준비가 짧지만 토지가 비싸다 |
| 도심 | 주거노출·이전비·민원이 크다 |
| 교외 | 토지와 회송의 중간 선택이다 |
| 원격 | 토지는 싸지만 인입선과 매일의 공차운행이 비싸다 |
| 기존기지 확장 | 기존 설비를 활용하지만 영업 중 단계공사가 필요하다 |
| 공유 | 초기투자가 작지만 타사 용량·시간표에 의존한다 |

지원 구조는 지상, 상부덮개, 반지하, 완전지하, 기존기지 확장, 공유다.
구조별 게임 보정치는 [차량기지 설계 문서](railway-depot-system.md#13-입지-형태별-이익과-손실)의
범위 안에서 사용한다.

## 사업비

```text
DepotCAPEX = 토지·권리취득
           + 부지조성·토목
           + 유치·검수설비와 건물
           + 본선 접속부·인입선
           + 건물 이전·교차부 처리
           + 환경저감
           + 지역환원
           + 설계·감리·시험
           + 자료품질 기반 예비비
```

국가 프로필의 건설비 보정치를 적용하되 토지가격과 구조비를 구분한다.
사업자·국가·지자체 부담률은 합계 100%여야 한다. 원장에는 총사업비가
아니라 협약상 사업자 부담분만 확정의무와 현금지출로 기록된다.

## 주민·지자체 협의

반대압력은 다음 요소를 0~100으로 정규화해 계산한다.

```text
25% 주거노출
+ 20% 건물·권리자 복잡도
+ 15% 야간소음·진동
+ 10% 조명·수질·공사교통
+ 10% 지역단절
+ 10% 자연·경관
+ 10% 절차불신
- 환경저감·지역편익(최대 35점)
```

선택 가능한 환경저감은 최소·표준·강화 3단계다. 지역환원은 없음,
녹지완충, 도로·보행연결, 상부 공공·상업시설, 회송선 여객화 패키지를
지원한다. 강한 대책은 수용도를 높이지만 사업비와 기간이 늘어난다.

협상이 부결되면 착공 명령이 거절된다. 플레이어는 구조, 환경대책,
지역환원, 후보 공개 수준 또는 비용분담을 수정한 뒤 다시 협상해야 한다.

## 회송 손실

```text
편도 회송거리 = 기지 접속선 + 접속점에서 가까운 종점까지 거리
연간 회송거리 = 편도거리 × 2 × 일일 입출고 편성 × 365
직접 회송비 = 차량·에너지·마모 + 승무·관제
총 회송비 = 직접 회송비 + 본선 슬롯 혼잡비
```

검증 기준인 30편성·편도 5km에서는 연간 109,500편성km,
차량·에너지비 ¥131.40 million, 승무·관제비 ¥19.71 million,
직접 회송손실 ¥151.11 million을 재현한다.

실제 영업 정산은 새 차량기지의 계산된 회송비, 기지 운영비와 상부시설
부대수입을 사용한다. 기존 즉시확보 기지는 종전 단순 계산을 유지해
저장본과 독립 O&M 데모의 호환성을 보존한다.

## 기준 후보 계산 예시

14편성 중형철도, 일일검사 2편성, 종점 인접 12만㎡ 지상 후보,
표준 환경저감·녹지완충, 조기공개와 3개 후보 비교 조건이다.

| 국가 | 필수면적 | P50 | P90 | 기간 | 연간 회송비 | 반대압력 | 종합점수 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 일본 | 69,663㎡ | ¥132.49bn | ¥159.82bn | 62개월 | ¥13.33m | 10.9 | 75.9 |
| 한국 | 69,663㎡ | ¥123.45bn | ¥148.92bn | 66개월 | ¥11.19m | 10.9 | 77.2 |

이는 실제 특정 차량기지의 예산이 아니라 2026년 JPY 기준 게임 초기
보정값이다. 토지단가 레이어가 연결되기 전에는 입지유형·건물밀도를 이용한
추정 토지단가를 사용한다.

## 상태와 원장

```text
planned
→ consultation 또는 negotiated
→ underConstruction
→ secured
```

- `planned`: 후보와 설계대책 선택 완료
- `consultation`: 협상 부결, 수정 필요
- `negotiated`: 비용분담·지역협약 성립
- `underConstruction`: 사업자 부담액 확정, 계약금과 월 기성 지급
- `secured`: 공사·입출고선·시험 완료, 개통 조건 충족

공사 중간 저장은 진행률, 지연, 기성금, 남은 확정의무, 난수상태를 모두
보존한다. 한 달 진행 중 현금이 부족하면 해당 월의 모든 변경을
원자적으로 되돌린다.

## 현재 경계와 다음 연결

경영 API는 클루드의 실제 `DepotSiteGeometry`를 직접 받고, 지도에서 현재
선택된 후보를 시나리오의 차량기지 계약 입력으로 전달한다. 선택한 후보가
다른 계획 노선에 연결돼 있으면 계약 전에 거절한다. 후보를 선택하지 않은
경우에만 기존 시나리오가 중단되지 않도록 `dataQuality: low`인 추정 후보를
명시적으로 생성한다. 시나리오 패널의 `차량기지 설계·협의`에서 구조,
환경대책, 지역환원, 3자 비용분담을 바꾸고 계약 전에 후보 평가 결과를
확인할 수 있다.
