# 교통사업 수주·사업성·경제성·경쟁회사 시스템 설계보고서

- 작성일: 2026-09-24
- 기준 시점·통화: 2026년, 일본 엔(JPY)
- 대상 국가: 일본을 기본 게임 국가로 하되 한국 제도를 비교·검증에 사용
- 플레이어 기본 역할: 버스·철도 운송회사의 대표이자 사업 스폰서
- 범위: 사업기회 생성, 제안·공모·허가, 입찰, 컨소시엄, 사업성·경제성·금융성, 경쟁회사, 협상·계약, 수주 후 이행
- 관련 상위 문서: [철도 건설·차량·차량기지 종합보고서](railway-construction-master-report-kr-jp-2026.md), [건설·경제·시뮬레이션 로드맵](construction-economy-roadmap.md)
- 상태: 구현 전 시스템 기준안. 법정 절차와 공개자료, 게임 규칙, 초기 밸런싱 값을 구분한다.

## 0. 결론

이 게임에서 노선을 만드는 방법은 하나가 아니다. 플레이어는 다음 네 가지 방식으로 교통사업을 확보한다.

```text
자체 사업: 회사가 노선과 재원을 마련해 허가를 받고 건설·운영
민간 제안: 회사가 공공에 사업을 제안하고 제3자 경쟁을 거쳐 시행권 확보
공공 공모: 정부·지자체가 정한 사업에 입찰해 건설·운영권 또는 운영권 확보
기존 사업 인수: 부실·철수 노선, 회사 지분 또는 운영권을 인수·재구축
```

버스는 소규모 자체면허·공공노선 계약·적자노선 위탁을 포함한다. 철도는 자체 신선, 공공·민간투자사업, 제2종 운영, 제3섹터 참여, 기존선 재구축을 포함한다.

반드시 다음 두 시장을 구분한다.

```text
플레이어가 수주하는 시장
  노선 사업권, 민자사업 시행권, 운영·유지관리 계약, 지역교통 서비스 계약

플레이어가 수주 후 발주하는 시장
  토목·궤도·전기·신호 공사, 차량 구매, 정비 위탁, 상업시설 임대
```

플레이어는 기본적으로 교통회사이지 종합건설사나 차량 제작사가 아니다. 컨소시엄에 시공사·금융사·제작사·전문운영사를 넣을 수 있지만, 그들의 공사와 제작 능력을 회사가 자동으로 소유하지 않는다.

사업은 `공공 경제성`, `회사 재무성`, `정부 재정부담`, `금융조달 가능성`, `기술·운영 실행성`, `입찰 경쟁력`을 각각 통과해야 한다. B/C가 높아도 회사가 손해를 보면 입찰하지 않을 수 있고, 회사 수익이 높아도 공공 편익이나 절차가 부족하면 선정되지 않는다.

경쟁회사는 장식용 점수가 아니다. 현금, 부채, 차량·기지, 노선망, 기술, 안전기록, 지역 적합성, 공사·운영 인력, 다른 입찰과의 중복을 가진 지속 객체다. 각 회사가 같은 정보를 보고 `입찰 / 컨소시엄 참여 / 포기`를 결정하므로 사업별 경쟁자 수가 달라진다.

## 1. 현실 제도를 게임 문법으로 바꾸는 원칙

### 1.1 한국과 일본의 가장 중요한 차이

| 구분 | 한국 | 일본 | 게임 처리 |
|---|---|---|---|
| 공공 철도계획 | 국가·도시철도망, 예타·기본계획과 공공 재원 관문이 강함 | 국가·광역·지방 계획과 기존 JR·사철의 경영전략이 함께 작동 | 국가 프로필별 기회 생성 가중치 차이 |
| 민간 참여 | 정부고시 또는 민간제안 민자사업, 공기업 직접사업, 별도 운영법인 등 | 기존 사업자의 자체연장, 제1·2·3종 철도사업, 제3섹터, PFI, 지역철도 재구축 등 | 한 종류의 `운영권 입찰`로 통합하지 않음 |
| 허가와 경쟁 | 사업계획 평가·협상·실시협약이 민자사업자 선정의 중심 | 철도사업 허가는 경영상·안전상 적절성을 심사하며, 모든 신선을 경쟁입찰로 배분하지 않음 | 허가형과 공모형을 별도 흐름으로 처리 |
| 공공성 평가 | 경제성·정책성·지역균형 등을 종합하며 민자적격성을 별도로 판단 | 효과·영향, 비용편익, 채산성, 사업 실행환경을 함께 평가 | B/C 하나로 승인하지 않음 |
| 지역 노선 유지 | 지자체 보조·준공영·운영위탁·사업 재구조화 | 상하분리, 제3섹터, 철도사업 재구축, 지역여객운송 서비스 공모 | 적자사업도 서비스 계약으로 수주 가능 |

한국의 2026년 민간투자사업기본계획은 정부고시사업, 민간제안사업, 대상지 공모형을 구분하고 BTO·BTL·혼합형·개량운영형 등 여러 추진방식을 둔다. 주무관청은 사업 발굴·타당성분석, 기본계획 또는 제3자 공고, 제안서 평가, 협상대상자 지정, 실시협약과 사업시행자 지정, 실시계획 승인, 이행 감독을 담당한다. [2026년 민간투자사업기본계획](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000274500&chrClsCd=010201)

일본 철도사업법은 철도사업을 하려면 노선과 사업종별로 허가를 받도록 하고, 사업수지견적 등을 제출하여 계획의 경영상·안전상 적절성과 수행능력을 심사한다. 이는 같은 노선을 모든 회사에 경매하는 절차와 다르다. [일본 철도사업법](https://laws.e-gov.go.jp/law/361AC0000000092), [철도사업 허가 절차](https://www.mlit.go.jp/onestop/061/images/061-012.pdf)

### 1.2 현실을 그대로 복사하지 않는 부분

- 실제 지자체·사업별 평가항목과 가중치는 다르므로 하나의 법정 배점처럼 표시하지 않는다.
- 실제 회사의 재무·안전·정치관계를 임의 점수화하지 않는다. 기본 게임에는 가상회사를 사용한다.
- 전국 회사 수를 한 입찰의 경쟁회사 수로 사용하지 않는다.
- 담합·뇌물은 기본 경영 수단으로 만들지 않는다. 경쟁 제한, 이해충돌, 허위자료는 조사·실격·제재 위험 사건으로만 다룬다.
- 보조금은 손실 삭제 버튼이 아니다. 서비스 의무·요금제한·성과평가·환수·정보공개가 따른다.

### 2.2 플레이어가 발주하는 계약

수주한 사업 안에는 다시 여러 계약이 생긴다.

| 발주 묶음 | 입찰 참가자 | 플레이어 판단 |
|---|---|---|
| 설계·사업관리 | 엔지니어링·설계회사 | 조사품질, 설계속도, 변경관리 |
| 토목·궤도·건축 | 종합·전문 시공사 | 가격, 공법경험, 장비, 안전, 수주잔량 |
| 신호·전력·통신 | 시스템 공급사 | 상호운용, 공급자 종속, 통합시험 |
| 철도차량·버스 | 제작사 | 성능, 가격, 생산슬롯, 정비지원 |
| 외부 정비 | 철도·버스 정비사업자 | 회송, 처리용량, SLA, 부품 |
| 금융 | 은행·펀드·채권투자자 | 금리, 만기, 약정, 헤지, 통제권 |
| 역·기지 상업시설 | 개발·임대사업자 | 선급금, 임대료, 수요창출, 장기통제 |

사업 수주 시 위 계약들이 자동 체결되지 않는다. 싼 수주가를 제시하고 하도급·차량·금융을 확보하지 못하면 금융종결에 실패하거나 손실사업이 된다.

## 3. 전체 수주 플레이 흐름

### 3.1 기회 발견부터 입찰 결정까지

```text
교통문제·개발계획·공모예고·매각대상 탐색
→ 사업기회 카드 생성
→ 비밀유지·자료실 접근 또는 자체 기초조사
→ 참가자격·면허·자본·실적 확인
→ 개략 노선·서비스·차량·기지·인력안 작성
→ 수요·사업비·운영비·공공편익의 범위 추정
→ 컨소시엄 후보와 금융기관 의향 확인
→ Bid / No-Bid 심의
→ 참가의향서·사전자격 제출
```

`No-Bid`는 패배가 아니다. 제안비용과 보증금을 아끼고 더 적합한 사업에 인력·자본을 남기는 경영 선택이다.

### 3.2 제안서 제출부터 사업시행자 지정까지

```text
질의응답·현장설명·데이터룸 검토
→ 컨소시엄·SPC 출자구조 확정
→ 기술안·운영안·재무모델·위험분담 작성
→ 내부 투자심의와 이사회 승인
→ 입찰보증·금융의향서 확보
→ 제안서·가격 제출
→ 적격성·필수조건 심사
→ 기술·가격·공익성 평가
→ 우선협상대상자 선정
→ 총사업비·요금·지원·기간·위험 협상
→ 대출확약·출자확약·선행조건 충족
→ 실시협약·사업시행자 지정
→ 금융종결
→ 실시계획·공사·차량·기지 단계로 이동
```

우선협상대상자는 아직 완전한 수주가 아니다. 협상이나 금융종결이 실패하면 차순위자로 넘어가거나 재공고·취소될 수 있다. 한국 민간투자 기본계획도 협상 실패 시 차순위 협상, 재공고 또는 사업 취소를 허용한다. [민간제안 평가·협상 절차](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000272048)

### 3.3 수주 후

```text
계약 발효·착수명령
→ 조사·설계·인허가
→ 공사·차량·기지·금융 계약 발주
→ 건설·제작·인력채용 병행
→ 성능·안전·통합시험
→ 영업개시
→ 서비스 KPI 측정·지급·감액
→ 재협상·자금재조달·증차·개량
→ 계약만료·재입찰·연장·자산인계
```

## 4. 국가별 수주 프로세스

### 4.1 한국 정부고시 민간투자사업

```text
주무관청 사업 발굴
→ 타당성·민자적격성 검토
→ 대상사업 지정
→ 시설사업기본계획/RFP 고시
→ 참가자격사전심사(PQ)
→ 사업계획 제출
→ 기술·가격 평가
→ 순위가 있는 협상대상자 지정
→ 실시협약 협상
→ 사업시행자 지정
→ 실시계획 승인·금융종결·착공
```

2026년 기본계획상 평가요소는 기술과 가격을 중심으로 구성하고, 가격에는 총사업비·수익률·수요·사용료·운영비·재정지원금 등이 포함될 수 있다. 참가자격에서는 시공·재무·운영능력을 볼 수 있으며, 사업별 고시가 실제 배점을 정한다. 따라서 게임도 모든 한국 사업에 한 배점표를 강제하지 않는다. [민간투자사업기본계획 평가규정](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000274500&chrClsCd=010201)

### 4.2 한국 민간제안사업

```text
플레이어 최초제안
→ 주무관청·PIMAC 검토와 민자적격성 조사
→ 채택 또는 반려
→ 제3자 제안공고
→ 최초제안자 변경제안 + 경쟁제안
→ 평가와 협상대상자 순위
→ 협상·실시협약·사업시행자 지정
```

최초제안자는 조사비와 아이디어 선점의 장점이 있지만 자동 수주하지 않는다. 제3자가 없으면 최초제안자가 협상대상자가 될 수 있고, 제3자가 있으면 함께 평가한다. 게임에서는 최초제안 우대가 공고에 있을 때만 적용하며, 우대율은 사업 객체에 저장한다.

### 4.3 일본 사업자 자체개발·허가형

```text
기존 노선망·개발사업과 연계한 회사 구상
→ 지자체·시설보유자·개발자와 조정
→ 수요·사업수지·자금·안전 계획
→ 철도사업 허가 신청
→ 경영상 적절성·안전·수행능력 심사
→ 공사시행 인가
→ 건설·완성검사·운임·개업 절차
```

이 흐름에서는 `최고 입찰점수`보다 계획의 허가 가능성과 이해관계자 합의, 자금조달이 중요하다. 동일 교통축에 다른 회사가 별도 계획을 추진할 수는 있지만, 모든 회사가 같은 RFP에 가격을 적어 내는 것은 아니다.

### 4.4 일본 공공·제3섹터·PFI형

```text
공공의 사업 발안 또는 민간 제안
→ PFI 도입 가능성·VFM·역할과 위험 검토
→ 실시방침·요구수준·계약안 공표
→ 참가자 모집·질의응답
→ 자격·기술·가격·VFM 평가
→ 우선교섭자 선정·공표
→ 기본협정·SPC·사업계약·금융종결
→ 필요한 철도사업 허가·공사 인가
```

일본 내각부 PFI 지침은 공공 직접시행과 PFI의 생애주기 재정부담을 현재가치로 비교하고, 민간이 부담할 위험의 가격도 양쪽 비교에 일관되게 반영하도록 한다. [일본 PFI 사업절차](https://www8.cao.go.jp/pfi/hourei/guideline/r5/pdf/process_guideline.pdf), [VFM 지침](https://www8.cao.go.jp/pfi/hourei/guideline/pdf/vfm_guideline.pdf)

### 4.5 일본 지역교통 유지·재구축형

지방정부와 기존 사업자가 상하분리·보조·서비스 변경을 협의하거나, 유지가 어려운 여객서비스의 새 제공자를 공모할 수 있다. 공모에는 구역·기존 서비스·계속할 서비스·사업자 조건·공공지원·기간·선정방식을 제시한다. [지역여객운송 서비스 공모 지침](https://wwwtb.mlit.go.jp/hokkaido/content/000273071.pdf), [철도사업 재구축](https://wwwtb.mlit.go.jp/kanto/tetudou/tiiki_tetudou/rebuild.html)

### 4.6 버스 사업

버스도 항상 노선 하나씩 공개입찰하는 것은 아니다. 기존 면허사업, 준공영 계약, 공공이 정한 노선의 한정면허·운영위탁, 적자노선 유지 공모를 분리한다. 한국에서는 광역버스 준공영제 노선 사업자 모집 사례가 있고, 일본은 지역서비스 유지가 어려울 때 공모형 프로포절 등으로 제공자를 고를 수 있다. [한국 광역버스 사업자 모집](https://www.molit.go.kr/brocm/USR/N0201/m_15265/dtl.jsp?id=95090157&lcmspage=17), [일본 지역교통 사업자 선정](https://wwwtb.mlit.go.jp/hokkaido/content/000174207.pdf)

## 5. 입찰 전 사전자격과 컨소시엄

### 5.1 참가자격 판정

다음 조건 중 하나라도 필수값에 미달하면 가격을 제출하기 전에 실격한다.

```text
법적 참가·면허 가능성
최소 자기자본·신용등급·출자확약
유사 건설 또는 운영 실적
지원하는 철도·차량·신호 기술
안전관리체계와 중대 제재 여부
핵심 인력·차량·기지·공급계약 확보 가능성
입찰보증과 이행보증 제공 능력
출자·계열·중복참여 제한
이해충돌·허위자료·체납·파산 제한
```

`qualified=false`인 회사는 낮은 가격으로 이길 수 없다.

### 5.2 컨소시엄 역할

| 역할 | 제공하는 것 | 요구하는 대가·제약 |
|---|---|---|
| 대표 스폰서 | 전략·최대 출자·정부 협상 | 의사결정권과 가장 큰 손실노출 |
| 철도·버스 운영사 | 면허·운영경험·인력체계 | 운영위탁비·지분·장기계약 |
| 시공사 | 공사 실적·원가·보증 | 도급이익·위험한도·설계조건 |
| 차량·시스템사 | 기술·납기·성능보증 | 공급계약·지식재산·장기부품 |
| 금융투자자 | 출자·신용·금융구조 | 목표수익률·배당·통제권 |
| 은행·대주단 | 장기대출·브리지론 | 이자·DSCR 약정·담보·스텝인권 |
| 개발회사 | 역세권·부대사업 | 개발권·수익배분·용도변경 조건 |
| 지자체·공공기관 | 부지·보조·시설·정책지원 | 요금·서비스·정보공개·공익조건 |

한 회사가 중복 역할을 할 수 있지만 능력치는 역할별로 검사한다. 컨소시엄 구성에는 시간과 협상비가 들며, 출자비율·의결권·완공보증·초과비용 부담을 합의하지 못하면 입찰 전에 붕괴한다.

### 5.3 입찰 자원

회사는 무한히 동시 입찰하지 못한다.

```text
BidCapacity = 가용 기획인력 + 엔지니어링 슬롯 + 법무·재무 슬롯
              + 입찰보증 한도 + 투자위원회 처리량

CapitalHeadroom = 현금 + 확약된 신용한도
                - 기존 계약 의무 - 비상유동성 - 다른 우선사업 예약액
```

입찰 여부의 경제적 기준은 다음처럼 계산한다.

```text
ExpectedBidValue = 수주확률 × 위험조정 Equity NPV
                 - 제안 준비비
                 - 우선협상 후 결렬확률 × 예상 보증·철수손실
                 - 자본·인력 점유의 기회비용
                 + 전략적 네트워크 옵션가치
```

값이 양수여도 회사의 손실한도·부채집중·지역집중을 넘으면 투자위원회가 거절할 수 있다.

대형 제안서는 조사·설계·법무·금융자문비가 발생하고 패배하면 대부분 매몰비용이 된다. 일부 공모는 탈락자 보상을 줄 수 있으나 자동 보상하지 않는다.

### 5.4 제안 준비기간과 비용

다음은 실제 법정기간이나 시장 평균이 아니라 2026년 JPY 기준 게임 초기범위다. 사업의 자료품질·설계요구·컨소시엄 수·공고기간에 따라 달라진다.

| 사업유형 | 제안 준비기간 | 제안·조사비 | 비고 |
|---|---:|---:|---|
| 소규모 특수·대체 버스 | 1~3개월 | 0.02~0.15억 엔 | 기존 차량·차고지 활용 전제 |
| 도시 버스노선 계약 | 2~6개월 | 0.05~0.30억 엔 | 차량·기사·차고지 계획 포함 |
| 철도 O&M·제2종 운영 | 6~12개월 | 1~5억 엔 | 자산실사·인력전환·운영안 포함 |
| 지역철도 인수·재구축 | 9~18개월 | 2~10억 엔 | 노후자산 실사와 공공협상 포함 |
| 정부고시 도시철도 PPP | 18~36개월 | 10~50억 엔 | 예비설계·금융·법무·컨소시엄 포함 |
| 대형 민간제안 철도 | 제3자 공고 전 24~60개월 | 20~100억 엔 | 초기 노선·수요·공법·공공협의 포함 |

회계에서는 `bidDevelopmentExpense`로 즉시 비용 처리하되, 내부 분석을 위해 사업별 누적액을 별도 기록한다. 낙찰 뒤에도 모든 제안비를 건설자산으로 자동 전환하지 않는다. 입찰보증은 현금비용이 아니라 한도와 유동성을 묶는 `contingentCommitment`로 기록하고, 귀책 철회·허위제안 때만 몰수한다.

## 6. 사업성·경제성 평가 체계

### 6.1 한 사업에 네 개의 사업계획을 둔다

| 계획 | 관점 | 핵심 질문 |
|---|---|---|
| `PublicCase` | 사회 전체 | 시간·접근성·안전·환경 편익이 사회적 비용보다 큰가 |
| `AuthorityCase` | 정부·지자체 | 예산과 우발부채를 감당하고 직접시행보다 나은가 |
| `SponsorCase` | 플레이어·출자자 | 투자금 대비 현금흐름과 위험이 충분한가 |
| `LenderCase` | 은행·채권자 | 나쁜 상황에서도 원리금을 제때 받을 수 있는가 |

네 계산은 같은 수요·공정·비용 원장을 참조하지만 현금흐름 범위와 할인율이 다르다. 하나의 `profitability` 숫자로 합치지 않는다.

### 6.2 공공 경제성

```text
사회적 편익 B = 통행시간 절감
                + 차량운행비 절감
                + 신뢰성·혼잡·사고 감소
                + 환경·배출 변화
                + 접근성 등 계량 가능한 추가편익

사회적 비용 C = 건설·차량·용지의 기회비용
                + 운영·유지·갱신비
                + 공사 중 불편·환경손실
                - 분석종료 시 잔존가치

B/C  = PV(B) / PV(C)
ENPV = PV(B) - PV(C)
EIRR = ENPV를 0으로 만드는 할인율
```

운임은 대체로 이용자에서 운영자로 이동하는 이전지출 성격이 있으므로 사회적 B/C에서 회사 매출처럼 편익에 다시 더하지 않는다. 세금·보조금·환승정산도 사회 전체와 개별 주체의 계산이 다르다.

한국 예비타당성조사는 경제성·정책성·지역균형 등을 종합하고, 2026년 총괄지침은 재무성을 `개별 사업주체의 현금유입과 유출` 관점으로 별도 정의한다. AHP 0.5 이상은 종합 타당성 판단에 쓰이지만 B/C 1만으로 자동 결정하는 구조가 아니다. [2026년 예비타당성조사 총괄지침](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000280172)

일본 철도 평가도 효과·영향, 비용편익, 채산성, 실행환경을 함께 본다. 2025년 개정 매뉴얼은 사회적 할인율 4%를 본값으로 두고 1%·2%를 참고 비교로 병기할 수 있게 했다. 이는 게임의 회사 할인율과 같은 값이 아니다. [일본 철도 프로젝트 평가 매뉴얼](https://www.mlit.go.jp/tetudo/tetudo_fr1_000040.html), [2025년 개정 설명](https://www.mlit.go.jp/policy/shingikai/content/001913645.pdf)

### 6.3 회사 재무성

```text
영업수입 = 순운임수입 + 공공 서비스대가 + 보조금
          + 광고·임대·개발 + 환승정산 + 기타 계약수입

영업비용 = 인건비 + 동력·연료 + 정비 + 차량·시설사용료
          + 보험·IT·역무·관리 + 세금·수수료 + 성과감액

FCF = 영업수입 - 영업비용 - 세금 - 갱신투자 - 운전자본증가

Project NPV = 투자·운영 전체 자유현금흐름의 현재가치
Project IRR = Project NPV가 0이 되는 수익률
Equity NPV  = 출자·배당·원금회수의 주주 현금흐름 현재가치
Equity IRR  = Equity NPV가 0이 되는 수익률
회수기간    = 누적 주주현금흐름이 0을 넘는 시점

운임회수율 = 순운임수입 / 철도·버스 운영비
영업마진   = (영업수입 - 영업비용) / 영업수입
ROIC       = 세후영업이익 / 평균투하자본
```

보조금을 받은 뒤의 회사 NPV와 보조금 전 사업 자체 NPV를 함께 표시한다. 손실을 보조금으로 가린 사업인지, 원래 자립 가능한 사업인지 구분해야 한다.

운임회수율이 100%를 넘는다고 건설부채·세금·갱신투자까지 감당한다는 뜻은 아니다. 영업마진이 양수여도 원리금과 차량교체 뒤 자유현금흐름은 음수일 수 있다.

### 6.4 금융조달 가능성

```text
CFADS = 원리금상환 전 가용현금흐름
DSCR  = 해당 기간 CFADS / 해당 기간 원리금상환액
LLCR  = 대출만기까지 CFADS 현재가치 / 남은 대출원금
DebtCapacity = 목표 DSCR을 훼손하지 않는 최대 차입액
```

게임 초기 투자심의 기준은 법정 공통값이 아니라 다음 제안값을 사용한다.

| 지표 | 안정 | 경계 | 거절 또는 조건변경 |
|---|---:|---:|---:|
| 기준수요 최소 DSCR | 1.30 이상 | 1.15~1.30 | 1.15 미만 |
| 하방수요 최소 DSCR | 1.10 이상 | 1.00~1.10 | 1.00 미만 |
| Equity NPV | 0 초과 | 0 부근 | 음수 |
| 공사 중 유동성 | 필요액 120% 이상 | 100~120% | 100% 미만 |
| 운영준비 현금 | 고정비 12개월 | 6~12개월 | 6개월 미만 |

은행·사업종류·보증·국가위험에 따라 기준은 달라진다. 기준 미달이면 출자 확대, 보조, 요금·기간 조정, 건설비 절감 또는 철회 중 하나를 선택한다.

### 6.5 손익분기 수요

```text
승객 1인당 공헌이익 = 평균 순운임 - 승객연동비용

연간 손익분기 승객 = (연간 고정운영비 + 시설사용료 + 목표이자
                    - 고정 공공대가 - 비운임수입)
                   / 승객 1인당 공헌이익

수요안전여유 = 기준예측승객 / 손익분기승객 - 1
```

`평균 순운임`은 표면 운임이 아니라 할인·정기권·무임·환승정산 후 회사에 남는 금액이다.

### 6.6 공공 재정부담과 VFM

```text
PSC = 공공 직접시행 생애주기비용 + 공공이 보유하는 위험 기대비용
PFI-LCC = 정부지급·보조·세제·보증·잔존의 현재가치
          + 공공에 남는 위험 기대비용
VFM 금액 = PSC - PFI-LCC
VFM 비율 = (PSC - PFI-LCC) / PSC
```

VFM이 양수라도 장래 지급액이 특정 연도 예산을 압박하면 추진할 수 없다. 정부는 다음을 별도로 본다.

- 연도별 확정지급액과 최대 우발지급액.
- 이용량·환율·금리·물가·해지 시 지급위험.
- 보조금 없이 유지할 대안과 서비스 축소안.
- 직접시행 대비 공기·품질·위험이전 효과.
- 계약 종료 후 자산 상태와 갱신비.

### 6.7 실행성과 전략 적합성

다음은 화폐화하기 어려워도 별도 관문이다.

- 상위 교통·도시계획 정합성.
- 노선·역·기지 부지와 주민협의 가능성.
- 기술 성숙도와 공급자 수.
- 차량·인력·정비·관제 확보 가능성.
- 기존망 직통·환승 계약 가능성.
- 플레이어 회사의 기존망과 시너지.
- 개통 목표까지의 임계경로와 일정 여유.
- 재난·장기수요 변화에 대한 회복력.

## 7. 수요와 재무 시나리오

### 7.1 하나의 수요예측을 믿지 않는다

| 시나리오 | 초기 게임 해석 | 사용처 |
|---|---|---|
| P90 하방 | 매우 불리하지만 가능한 수요 | 생존·부도·대출약정 검사 |
| P75 보수 | 대체수단 경쟁과 개발지연 반영 | 대주단 심사 |
| P50 기준 | 가장 가능성이 높은 중앙값 | 가격·운영·기준 사업성 |
| P25 상방 | 개발과 환승효과가 좋은 경우 | 증차·확장 필요성 |
| 스트레스 | 공사비·금리·수요가 동시에 악화 | 투자위원회·정부 우발부담 |

표기의 P90은 여기서 `수요가 이 값 이상일 가능성이 높은 보수값`이라는 내부 정의로 고정한다. 팀 전체에서 반대 정의를 섞지 않는다.

### 7.2 민감도 축

- 건설비 `-10 / 기준 / +20 / +40%`.
- 개통 `정시 / +1년 / +3년`.
- 수요 `-30 / -15 / 기준 / +15%`.
- 평균 순운임 `-10 / 기준 / +10%`.
- 운영비 `기준 / +10 / +25%`.
- 금리 `기준 / +1 / +3%p`.
- 공공지원 `확정 / 지연 / 일부삭감`.
- 역세권 개발 `정시 / 지연 / 취소`.

민감도는 한 변수만 바꾸는 표와 여러 변수가 함께 악화되는 스트레스 테스트를 모두 제공한다.

### 7.3 예측 편향

모든 회사는 참값을 알지 못한다.

```text
회사 수요예측 = 공통 기초수요
               × 회사의 분석모형 편향
               × 네트워크 시너지 판단
               × 정보품질 오차

실제 수요 = 도시·인구·일자리·서비스·경쟁수단의 실현값
```

낙관적인 경쟁사는 낮은 보조금이나 높은 사용료를 제시해 수주할 가능성이 높지만, 운영기에 재무위험이 커진다. 게임은 낙찰을 곧 성공으로 보상하지 않는다.

### 9.5 가격점수

무조건 최저가격이 만점을 독식하지 않게 범위와 하한을 둔다.

```text
낮을수록 좋은 항목:
PriceScore = PriceWeight × clamp(최저 적격제안 / 해당 제안, 0, 1)

높을수록 좋은 항목:
PriceScore = PriceWeight × clamp(해당 제안 / 최고 적격제안, 0, 1)
```

요구보조금·정부지급금처럼 낮을수록 좋은 항목과 시설사용료·수익공유처럼 높을수록 좋은 항목을 구분한다. 발주기관이 기준가격 방식이나 비선형 곡선을 공고했다면 그 공식을 사업 객체에 저장한다. 비정상적으로 낮은 가격은 원가근거를 요구하고, 설명 실패 시 감점 또는 실격한다.

## 10. 경쟁회사 수와 시장 구성

### 10.1 현실 시장의 숫자를 해석하는 법

일본 국토교통성 자료상 2024년 7월 1일 전국 철궤도 사업자는 218자이고, 여객철도는 208자다. 여객 부문은 JR 6자, 사철 191자, 공영 11자로 분류되며 사철 중 대형 민철은 16자다. 하지만 홋카이도의 지역사업자와 수도권 대형 사철이 같은 도시철도 공모에 모두 참여하는 것은 아니다. 이 숫자는 회사 생태계 규모의 근거이지 한 입찰의 예상 참가자 수가 아니다. [일본 교통정책백서의 사업자 수](https://www.mlit.go.jp/sogoseisaku/transport/content/001890733.pdf), [철도통계연보](https://www.mlit.go.jp/tetudo/tetudo_tk6_000032.html)

한국도 공기업, 도시교통공사, 민자철도 법인, 위탁운영사 등이 함께 존재한다. 철도산업정보센터의 도시철도 통계는 기관별 실적을 제공하지만, 이 기관 전부가 모든 신규 사업의 입찰 후보라는 뜻은 아니다. [한국 철도 운영기관 통계](https://www.kric.go.kr/jsp/industry/rss/cityorganpassList.jsp?q_fdate=2025)

### 10.2 게임 세계에 생성할 회사 수

지도 밖 전국회사를 모두 매일 시뮬레이션하지 않는다. 활동시장별로 다음 수의 지속 경쟁회사를 생성한다. 이는 게임 성능과 경쟁 다양성을 위한 초기값이다.

| 시나리오 규모 | 운송사업 경쟁회사 | 금융·개발 스폰서 | 시공·차량 등 공급회사 | 설명 |
|---|---:|---:|---:|---|
| 소도시·지역권 | 6~10 | 2~4 | 8~14 | 버스·지역철도 중심, 무응찰 가능 |
| 표준 대도시권 | 14~22 | 4~8 | 16~28 | 기존망 사업자와 신규 컨소시엄 공존 |
| 초대형 광역권 | 24~36 | 6~12 | 24~40 | 여러 철도·버스 시장과 동시 입찰 |

같은 그룹의 버스회사·철도회사·개발회사는 별도 법인이어도 `corporateGroupId`로 묶는다. 계열사가 서로 위장경쟁하지 못하고, 출자·보증·자본한도를 공유하게 한다.

| 농어촌·적자 버스 | 0~4 | 보조가 부족하면 무응찰 |
| 토목 공구 발주 | 3~8 | 전문 공법·보유장비가 필터 |
| 차량 발주 | 2~5 | 규격·생산슬롯·인증이 필터 |
| 역 상업·개발권 | 3~10 | 교통 운영보다 진입 가능한 업종이 넓음 |

입찰자 0명은 오류가 아니다. 요구조건이 과도하거나 보조·예정가격이 낮으면 무응찰 후 조건수정, 재공고, 직접운영 또는 사업취소가 발생한다. 1개 컨소시엄만 제출하면 단독응찰 심사와 원가검증을 강화한다. 한국 기본계획도 단독응찰로 협상대상자가 선정될 수 있음을 전제로 후속 시공자 경쟁을 요구할 수 있게 한다. [단독응찰 처리 근거](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000274500&chrClsCd=010201)

### 10.4 입찰 참가자 수 계산

```text
PotentialPool = 지역에서 활동하거나 진입 가능한 회사

EligiblePool = PotentialPool
             ∩ 법적자격
             ∩ 기술규격
             ∩ 최소실적
             ∩ 자본·보증한도
             ∩ 입찰·공사·운영 가용용량

InterestScore(company, opportunity) =
    0.22 × 전략적합도
  + 0.18 × 예상 주주수익
  + 0.14 × 기존망 시너지
  + 0.12 × 승산
  + 0.10 × 지역·기술 경험
  + 0.09 × 가용자본
  + 0.08 × 경영진 위험선호
  + 0.07 × 후속사업 가치
  - 입찰비용·과부하·집중위험 패널티

입찰참가 = 적격 && InterestScore ≥ 회사별 참가문턱
```

난수는 회사 판단의 작은 오차에만 쓰고, 시드로 재현한다. 경쟁자 수를 플레이어 수준에 맞춰 고무줄처럼 조정하지 않는다.

## 12. 경쟁의 두 단계

### 12.1 수주 경쟁

- 가격·요구보조·시설사용료.
- 노선·역·차량·서비스 설계.
- 공기와 단계개통.
- 자금조달 확실성.
- 위험 수용과 계약조건.
- 안전·성과·지역편익.

### 12.2 개통 후 시장 경쟁

수주가 끝나도 경쟁은 계속된다.

- 평행 철도·버스·자동차와 통행시간·요금·빈도 경쟁.
- 환승협약·공동승차권과 고객 잠금효과.
- 첫차·막차·급행·좌석·정시성 차별화.
- 역세권 개발과 비운임수익 경쟁.
- 기사·기관사·정비인력 채용 경쟁.
- 차량·부품·공사 슬롯 선점.
- 부실회사의 노선 매각과 인수합병.

완전 독점 노선이라도 공공계약 KPI, 자동차, 재택·인구변화가 압력으로 작용한다. 반대로 평행노선 경쟁이 심하면 각 회사의 수요가 단순 합산되지 않는다.

### 12.3 회사 전체 사업성과 대시보드

개별 노선의 흑자와 회사 전체의 건전성을 분리한다. 대시보드는 다음 다섯 묶음을 동시에 보여준다.

| 묶음 | 주요 지표 | 잘못 해석하면 생기는 문제 |
|---|---|---|
| 수주 파이프라인 | 관찰·PQ·입찰·우선협상·금융종결 건수와 금액 | 공고금액 전체를 확정매출로 오인 |
| 수주 성과 | 적격통과율, 수주율, 우선협상→금융종결 전환율, 제안비/수주 | 저가 적자수주를 높은 수주율로 미화 |
| 계약잔고 | 남은 계약수입, 회사 귀속분, 예상 기여이익, 위험조정잔고 | 컨소시엄 총액을 회사 매출로 중복계상 |
| 재무 | 현금, 영업현금흐름, EBITDA, 순부채, 이자보상, 미납입출자 | 회계이익만 보고 공사 중 현금고갈 무시 |
| 운송·서비스 | 승객·인km, 운임회수율, 정시율, 결행률, 혼잡, 가용률, 사고 | 승객 수만 늘리고 비용·품질 악화 무시 |

핵심 산식:

```text
PQ 통과율 = PQ 통과건수 / PQ 제출건수
입찰 수주율 = 최종수주건수 / 유효입찰건수
가치기준 수주율 = 수주한 회사귀속 위험조정 NPV / 제출한 양수 NPV 합계
제안효율 = 수주사업의 예상 기여이익 / 전체 제안 준비비

계약잔고 = 각 계약의 미이행 회사귀속 매출 합계
위험조정잔고 = Σ(미이행 기여이익 × 이행확률 × 회수확률)
수주집중도 = 최대 고객·지역·계약의 위험조정잔고 / 전체 위험조정잔고

순부채 = 이자부채 - 현금성자산
이자보상배율 = 영업이익 또는 EBITDA / 순이자비용
미납입출자 = 체결 계약상 앞으로 납입해야 할 자기자본

승객시장점유율 = 회사 승객인km / 해당 시장 전체 승객인km
공급점유율 = 회사 좌석·입석 수용인km / 해당 시장 전체 공급인km
```

`계약금액`, `회사 매출`, `현금유입`, `이익`은 서로 다른 값이다. 예를 들어 30% 지분 컨소시엄의 총사업비 전액을 플레이어 수주액으로 잡지 않는다. 시설사용료를 포함한 총수입도 통과매출과 회사 부가가치를 구분한다.

회사 평가는 단기 수주율보다 다음 균형을 본다.

- 3~5년 수주 파이프라인이 있으나 동시에 감당할 수 있는 수준인가.
- 손실사업을 제외한 위험조정잔고가 양수인가.
- 건설 중 출자와 운영 중 차량교체를 감당할 현금이 있는가.
- 특정 지자체·노선·제작사에 지나치게 의존하지 않는가.
- 정시성·안전·가용률이 다음 입찰의 평판을 높이고 있는가.
- 성장 때문에 부채·인력·기지 용량이 먼저 한계에 도달하지 않는가.

### 14.3 정보 표시

단일 숫자 대신 다음을 보여준다.

```text
사업비: P50 3,200억 엔 / P80 3,850억 엔
개통: 2036년 4월, -6개월~+24개월
일수요: P90 11만 / P50 15만 / P25 18만 명
Equity IRR: 6.2~10.4%
입찰 참가예상: 2~4개 컨소시엄
수주확률: 35~55%
수주 후 재무곤란확률: 18%
```

수주확률은 경쟁사 추정이므로 정확한 값이 아니며 정보품질 등급을 함께 표시한다.

## 15. 예시 — 일본 공공소유 도시철도 운영권

가정:

```text
시설: 지방정부·제3종 사업자가 건설·보유
플레이어: 제2종 운송과 차량·기지 운영을 20년간 담당
수입: 운임을 회사가 받되 매년 시설사용료 지급
공공지원: 저수요 구간 기본 서비스대가
경쟁: 적격 후보 4개, 실제 입찰 3개 예상
```

플레이어 검토 순서:

1. 규격과 차량·기지 확보 가능성을 검사한다.
2. 목표 배차에서 편성·인력·전력·정비비를 계산한다.
3. 환승정산 뒤 순운임과 P90/P50 수요를 계산한다.
4. 시설사용료·서비스대가·성과감액을 반영한다.
5. 차량투자와 운영준비비를 포함해 Equity NPV·IRR을 계산한다.
6. P90에서 DSCR과 현금고갈 여부를 검사한다.
7. 경쟁사 유형을 보고 시설사용료와 서비스 수준을 조정한다.
8. 이길 수는 있지만 P90에서 부도나는 가격이면 No-Bid 또는 조건부 입찰한다.

세 경쟁사의 예상 행동:

| 경쟁사 | 예상 제안 | 약점 |
|---|---|---|
| 기존망 사업자 | 높은 시설사용료, 환승·기지 공유 | 기존망 인력비와 혼잡 |
| 저비용 운영사 | 낮은 운영대가, 표준서비스 | 철도차량·중정비 파트너 의존 |
| 개발연계 컨소시엄 | 역 상업권 대가로 낮은 보조 | 개발 지연 시 재무 악화 |

플레이어는 세 회사보다 무조건 싸게 쓰는 대신, 기존 버스망 연계·에너지 절감·단계적 증차로 재무성과 기술점수를 함께 높일 수 있다.

## 18. 구현 순서

### 18.1 1차 — 사업기회와 Bid/No-Bid

- 가상 발주기관 1곳, 가상 경쟁 운송사 5곳.
- `O&M-RAIL` 한 종류.
- 공개정보·추가조사·마감일.
- 참가자격과 간단한 P50/P90 손익.
- 참가·포기 결정과 매몰 제안비.

### 18.2 2차 — 경쟁입찰

- 컨소시엄 역할과 출자.
- 적격성·기술·가격 3단계 평가.
- 경쟁사 Bid/No-Bid와 비공개 제안.
- 단독응찰·무응찰·재공고.
- 우선협상과 차순위 전환.

### 18.3 3차 — 금융과 계약

- Project/Equity NPV·IRR, DSCR, 손익분기 수요.
- 대출·출자확약·보증·금융종결.
- 위험배분과 계약 KPI.
- 공공 지급·감액·보조·시설사용료.

### 18.4 4차 — 건설·차량·기지 연결

- 수주 사업을 기존 `RailProject`로 변환.
- 시공사·차량 제작사·정비 계약 재입찰.
- 공정 지연과 금융비, 개통 지연 손실 연결.
- `OpenReady` 통과 후 수입 발생.

### 18.5 5차 — 장기 경쟁

- 병행노선 수요경쟁과 환승협약.
- 경쟁사 자본·부채·차량·기지·수주잔량.
- 계약 갱신·재입찰·인수합병·파산·스텝인.
- 사후평가와 회사 평판의 다음 입찰 반영.

## 19. 기존 M0~M6 로드맵과 연결

| 단계 | 추가할 수주 시스템 |
|---|---|
| M0 | 사업·회사·입찰·계약 ID, 국가 프로필, 단위·가격연도 |
| M1 | 제출기한·평가·협상·금융종결이 같은 게임 시계를 사용 |
| M2 | 회사·컨소시엄·현금·보증·입찰비·계약 원장과 저장 |
| M3 | 수주 계약을 건설 프로젝트와 발주 패키지로 변환 |
| M4 | 운영수입·공공대가·KPI·감액·시설사용료·경쟁수요 |
| M5 | 상세 B/C·VFM·재무모델·위험배분·회사별 AI 전략 |
| M6 | 다수 회사·동시 입찰·30년 계약·파산·재입찰 장기검증 |

수주 시스템의 최소 골격은 M2에서 만들고, M3 건설과 M4 운영을 잇는 입구로 사용한다. 전체 금융·경쟁 깊이는 M5에서 확장한다.

## 20. 테스트 기준

1. B/C가 높지만 회사 NPV가 음수인 사업을 구분한다.
2. 회사 수익이 높지만 VFM·재정부담 때문에 공공이 거절하는 사업을 구분한다.
3. 최초제안자가 제3자에게 패할 수 있다.
4. 우선협상자가 금융종결에 실패하면 차순위자로 넘어간다.
5. 경쟁자 수는 적격성·전략·자본에 따라 0명도 될 수 있다.
6. 경쟁사는 동시에 모든 사업에 입찰하지 못한다.
7. 낮은 입찰가로 이긴 회사가 운영기에 실제 손실을 본다.
8. 단독응찰은 자동 낙찰되지 않고 가격·원가 검증을 받는다.
9. 공공 지급형 계약은 수요하락보다 KPI 감액에 더 민감하다.
10. 순비용 계약은 수요·운임 위험이 플레이어에게 남는다.
11. 수주 후 시공사·차량 입찰이 실패하면 금융비와 개통일이 변한다.
12. 저장·불러오기 후 경쟁사 현금·입찰·계약·평가 결과가 동일하다.
13. 같은 난수 시드와 입력은 같은 입찰 결과를 낸다.
14. 계열회사는 별도 회사로 중복입찰하거나 자본한도를 이중사용하지 못한다.
15. 계약 종료 시 자산상태 미달이면 인계보수비가 발생한다.

## 21. 확정 규칙과 보정 대상

### 확정할 설계 원칙

- 허가형, 공모형, 민간제안형, 인수형을 분리한다.
- 플레이어 수주와 플레이어의 후속 발주를 분리한다.
- 공공 경제성, 정부 재정부담, 회사 재무성, 금융성을 분리한다.
- 우선협상, 사업시행자 지정, 금융종결, 착공을 별도 상태로 둔다.
- 경쟁회사는 지속 자산·재무·평판·수주잔량을 가진다.
- 사업별 경쟁자 수는 적격성과 Bid/No-Bid 결과로 결정한다.
- 전국 사업자 수를 한 입찰 참가자 수로 사용하지 않는다.
- 낙찰보다 계약기간 전체의 이익과 생존을 성공 기준으로 삼는다.

### 플레이테스트·자료로 보정할 값

- 사업유형별 실제 제안비용과 준비기간.
- 배점·가격점수 곡선·최소통과점수.
- 회사 규모별 목표수익률·DSCR·부채한도.
- 지역·사업유형별 적격 후보와 실제 입찰자 분포.
- 수요예측 오차와 경쟁사 낙관편향.
- 서비스 KPI 감액·보너스 수준.
- 계약별 정부지원·사용료·수익공유 조건.
- 인수합병·파산·재공고의 발생빈도.

## 22. 최종 권고

첫 버전에서는 대형 철도 PPP 전체를 바로 구현하지 않는다. `공공소유 철도 운영권 O&M 공모` 하나로 수주 사이클을 먼저 완성한다.

```text
사업기회 발견
→ 조사
→ Bid/No-Bid
→ 경쟁사 2~4곳과 입찰
→ 적격·기술·가격 평가
→ 우선협상
→ 계약·금융종결
→ 차량·기지·인력 준비
→ 운영
→ KPI 지급·감액
→ 계약 갱신
```

그다음 한국 민간제안 BTO와 일본 자체허가형을 추가한다. 이 순서면 수주 경쟁의 재미를 빠르게 검증하면서도 기존 건설·차량·차량기지 시스템과 바로 연결할 수 있다.
